# XXE Prevention

---

# 1. Main Cause of XXE

- XXE usually happens because of:
    
    - Unsafe XML parsing
        
    - Outdated XML libraries
        
    - External entity support enabled
        
- XML input is mostly handled by XML parsers/libraries, not manually by developers.
    

---

# 2. Avoid Outdated Components

## Update XML Libraries

- Use latest XML parsers/libraries.
    
- Older libraries may allow unsafe external entity loading.
    

Example (PHP):

```php
libxml_disable_entity_loader(false);
```

- Deprecated in PHP 8.
    
- Unsafe because it enables external entities.
    

---

# Warning from PHP

```text
This function has been DEPRECATED as of PHP 8.0.0.
Relying on this function is highly discouraged.
```

---

# Update Other XML Related Components

Also update:

- SOAP libraries
    
- SVG processors
    
- PDF processors
    
- XML APIs
    
- XML parsers
    

Because they may parse XML internally.

---

# Update General Components Too

Not only XML libraries:

- npm packages
    
- Node modules
    
- Framework dependencies
    

Modern editors (VSCode etc.) warn about outdated components.

---

# 3. Safe XML Configurations

## Disable DTDs

Prevent custom document type definitions.

```xml
<!DOCTYPE root [...]>
```

---

## Disable External XML Entities

Prevent:

```xml
<!ENTITY xxe SYSTEM "file:///etc/passwd">
```

---

## Disable Parameter Entities

Prevent:

```xml
<!ENTITY % file SYSTEM "file:///etc/passwd">
```

---

## Disable XInclude Support

Prevent XML file inclusion attacks.

---

## Prevent Entity Reference Loops

Protect against Billion Laughs / XML DoS attacks.

Example:

```xml
<!ENTITY a "&a;&a;&a;">
```

---

# 4. Proper Error Handling

Error-based XXE depends on visible runtime errors.

## Prevention

- Disable PHP/XML runtime error display.
    
- Use proper exception handling.
    

Bad:

```text
XML parser error at /var/www/html/
```

Good:

- Generic error message
    
- No internal details exposed
    

---

# 5. Prefer JSON Instead of XML

XML introduces:

- DTDs
    
- Entities
    
- External references
    

JSON is safer and simpler.

Preferred:

- REST APIs (JSON)
    

Avoid if possible:

- SOAP APIs (XML)
    

---

# 6. Use WAF (Extra Layer)

Web Application Firewall can:

- Detect XXE payloads
    
- Block malicious XML requests
    

BUT:

- WAF is not full protection
    
- Attackers may bypass WAFs
    

So:

- Fix backend vulnerabilities first.
    

---

# Important Prevention Checklist

```text
✓ Update XML libraries
✓ Disable external entities
✓ Disable DTDs
✓ Disable parameter entities
✓ Disable XInclude
✓ Prevent entity loops
✓ Hide runtime errors
✓ Use JSON instead of XML
✓ Keep components updated
✓ Use WAF as extra protection
```
