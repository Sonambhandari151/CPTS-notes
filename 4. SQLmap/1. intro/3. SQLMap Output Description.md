
# 1. URL Content is Stable

## Log Message

```bash
target URL content is stable
```

## Meaning

The response of the web page remains almost the same when identical requests are sent multiple times.

## Importance

- Helps SQLMap compare responses accurately.
    
- Easier to identify differences caused by SQL Injection payloads.
    
- Reduces false positives.
    

## Example

```bash
?id=1
```

Repeated requests return the same content.


# 6. Level and Risk Values

## Log Message

```bash
extending provided level (1) and risk (1)
```

# Risk

Defines how aggressive payloads are.

|Risk|Meaning|
|---|---|
|1|Safe|
|2|Medium|
|3|Aggressive|

# Level

Defines how many tests and parameters are checked.

|Level|Meaning|
|---|---|
|1|Basic|
|5|Extensive|

## Importance

Higher level/risk:

- increases detection capability
    
- increases requests and scan time

# 8. Parameter Appears Injectable

## Log Message

```bash
GET parameter 'id' appears to be 'AND boolean-based blind' injectable
```

# Boolean-Based Blind SQLi

## Meaning

The application does not display SQL errors, but response behavior changes depending on TRUE or FALSE conditions.

## Example

```sql
?id=1 AND 1=1
```

TRUE condition → normal response

```sql
?id=1 AND 1=2
```

FALSE condition → different response

## Importance

Used when errors are hidden.

---

# 9. Time-Based Comparison Statistical Model

## Log Message

```bash
time-based comparison requires a larger statistical model
```

# Time-Based Blind SQLi

## Meaning

SQLMap detects SQL Injection by causing intentional delays in server responses.

## Example Payloads

### MySQL

```sql
SLEEP(5)
```

### MSSQL

```sql
WAITFOR DELAY '0:0:5'
```

## Importance

Useful when:

- no errors shown
    
- no visible response changes

# 10. Extending UNION Query Injection Tests

## Log Message

```bash
automatically extending ranges for UNION query injection technique tests
```

# UNION-Based SQLi

## Meaning

Uses UNION queries to combine attacker-controlled results with original query results.

## Example

```sql
UNION SELECT username,password FROM users
```

## Importance

Allows direct extraction of database data.

---

# 11. ORDER BY Technique Appears Usable

## Log Message

```bash
ORDER BY technique appears to be usable
```

## Meaning

SQLMap uses ORDER BY statements to determine the number of columns.

## Example

```sql
ORDER BY 1
ORDER BY 2
ORDER BY 3
```

When an error occurs:

```sql
Unknown column
```

the previous number indicates valid column count.

# Important SQLMap Concepts Summary

| Concept              | Purpose                      |
| -------------------- | ---------------------------- |
| Stable Content       | Easier response comparison   |
| Dynamic Parameter    | Indicates backend processing |
| Heuristic Test       | Initial SQLi detection       |
| Boolean Blind        | TRUE/FALSE based detection   |
| Time-Based Blind     | Delay-based detection        |
| UNION SQLi           | Direct data extraction       |
| ORDER BY             | Finds column count           |
| Reflection Filtering | Removes noisy responses      |
| Risk                 | Payload aggressiveness       |
| Level                | Scan depth                   |
| Session Files        | Save scan results            |
