# **Command Injection – Other Injection Operators Notes**

## **1. AND Operator (&&)**

### **Payload**

```bash
127.0.0.1 && whoami
```

### **Executed Command**

```bash
ping -c 1 127.0.0.1 && whoami
```

---

### **Local Execution Result**

- `ping` runs successfully
    
- `whoami` executes after it
    
- Output shows both results
    

---

### **Behavior**

- Executes **second command only if first succeeds**
    

---

### **Web Application Test**

- Payload used in HTTP request
    
- URL-encoded before sending
    
- Result:
    
    - Both command outputs received
        
    - Injection successful
        

---

## **2. OR Operator (||)**

### **Payload**

```bash
127.0.0.1 || whoami
```

---

### **Executed Command**

```bash
ping -c 1 127.0.0.1 || whoami
```

---

### **Result**

- Only `ping` executes
    
- `whoami` does NOT execute
    

---

### **Reason**

- First command returns:
    
    - Exit code **0 (success)**
        
- So second command is skipped
    

---

### **Behavior**

- Executes **second command only if first fails**
    

---

## **3. Forcing OR Execution**

### **Payload**

```bash
|| whoami
```

---

### **Executed Command**

```bash
ping -c 1 || whoami
```

---

### **Result**

- `ping` fails (no IP provided)
    
- Error message shown
    
- `whoami` executes
    

---

### **Web Application Result**

- Only `whoami` output shown
    
- Cleaner output achieved
    

---
