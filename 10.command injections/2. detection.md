
# **Command Injection – Detection

## **1. Detection Concept**

- Detecting command injection is **same as exploiting it**
    
- Method:
    
    - Append malicious command using injection techniques
        
- If output **changes from normal result → vulnerability exists**
    

---

## **2. Advanced Detection**

- For advanced cases:
    
    - Use **fuzzing**
        
    - Perform **code review**
        
- Build payload **step-by-step** until injection works
    

---

## **3. Scope of Module**

- Focus is on:
    
    - **Basic command injection**
        
- Condition:
    
    - User input is **directly used**
        
    - No **sanitization**
        

---

## **4. Example: Host Checker Application**

- Web app asks for:
    
    - **IP address**
        
- Purpose:
    
    - Check if host is alive
        

### **Test Input**

```
127.0.0.1
```

### **Output**

- Returns result of **ping**
    
- Shows localhost is alive
    

---

## **5. Backend Command Guess**

- Based on output:
    

```bash
ping -c 1 OUR_INPUT
```

- Input is directly inserted into command
    

---

## **6. Vulnerability Condition**

- If input is:
    
    - Not sanitized
        
    - Not escaped  
        → Command injection possible
        

---

## **7. Command Injection Methods**

|Operator|Character|URL Encoded|Execution|
|---|---|---|---|
|Semicolon|;|%3b|Both|
|New Line|\n|%0a|Both|
|Background|&|%26|Both (second shown first)|
|Pipe|\||%7c|Both (only second shown)|
|AND|&&|%26%26|Both (only if first succeeds)|
|OR|\||%7c%7c|Second (only if first fails)|
|Sub-Shell|``|%60%60|Both (Linux only)|
|Sub-Shell|$()|%24%28%29|Both (Linux only)|

---

## **8. Injection Usage**

- Format:
    

```
Expected_Input + Operator + Malicious_Command
```

---

## **9. Important Note**

- Works across:
    
    - PHP
        
    - .NET
        
    - NodeJS
        
    - Linux / Windows / macOS
        

---

## **10. Exception**

- `;` (semicolon):
    
    - ❌ Not work in **Windows CMD**
        
    - ✔ Works in **Windows PowerShell**
