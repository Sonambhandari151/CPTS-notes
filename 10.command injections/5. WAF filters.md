# **Command Injection – Identifying Filters Notes**

## **1. Injection Mitigation Techniques**

- Developers may use:
    
    - **Blacklisted characters/words (back-end)**
        
    - **Web Application Firewall (WAF)**
        

---

## **2. Web Application Firewall (WAF)**

- Provides:
    
    - Broader protection
        
- Can detect:
    
    - Command injection
        
    - SQL injection
        
    - XSS attacks
        

---

## **3. Filter/WAF Detection**

### **Observation**

- Using operators like:
    
    - `;`
        
    - `&&`
        
    - `||`
        
- Result:
    
    - Error → **"Invalid input"**
        

---

## **4. Meaning of Error**

- Indicates:
    
    - Security mechanism detected payload
        
    - Request denied
        

---

## **5. Where Detection Happens**

### **Case 1: Same Page Error**

- Error shown in output field
    
- Means:
    
    - **Handled by backend (PHP)**
        

### **Case 2: Different Page**

- Shows:
    
    - IP
        
    - Request details
        
- Means:
    
    - **Blocked by WAF**
        

---

## **6. Payload Used**

```bash
127.0.0.1; whoami
```

### **Components**

- Valid IP
    
- `;` (semicolon)
    
- Space
    
- `whoami` command
    

---

## **7. Possible Detection Causes**

- Blacklisted:
    
    - Character (`;`)
        
    - Command (`whoami`)
        
    - Or both
        

---

## **8. Blacklisted Characters**

### **Example PHP Filter**

```php
$blacklist = ['&', '|', ';', ...SNIP...];
foreach ($blacklist as $character) {
    if (strpos($_POST['ip'], $character) !== false) {
        echo "Invalid input";
    }
}
```

---

### **Working**

- Loops through blacklist
    
- Checks input
    
- If match found → request denied
    

---

## **9. Identifying Blacklisted Character**

### **Method**

- Test **one character at a time**
    

---

### **Step**

```id="v5pt6n"
127.0.0.1;
```

---

### **Result**

- Still shows **Invalid input**
    

---

### **Conclusion**

- `;` is **blacklisted**
