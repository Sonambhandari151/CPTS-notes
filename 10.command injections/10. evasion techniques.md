
# 🔹 1. What are Evasion Tools?

##  Idea

- Manual obfuscation (quotes, reverse, base64) may fail against:
    
    - WAF (Web Application Firewall)
        
    - Advanced filters
        
- So we use **automated tools** to generate bypass payloads
    

---

# 🐧 2. Linux Tool – Bashfuscator

## 🔹 Purpose

- Automatically converts normal bash commands into:
    
    - obfuscated / unreadable commands
        
- Helps bypass filters blocking:
    
    - keywords (`cat`, `whoami`)
        
    - characters (`;`, spaces, `/`)
        

---

## 🔹 Installation Steps

```bash
git clone https://github.com/Bashfuscator/Bashfuscator
cd Bashfuscator
pip3 install setuptools==65
python3 setup.py install --user
```

---

## 🔹 Run tool

```bash
cd ./bashfuscator/bin/
./bashfuscator -h
```

---

## 🔹 Basic usage

```bash
./bashfuscator -c 'cat /etc/passwd'
```

### Output:

- Random complex payload
    
- Very long (hundreds to millions of characters)
    

---

## ⚠️ Problem

- Output is:
    
    - too large ❌
        
    - sometimes unusable in web injection ❌
        

---

## 🔹 Optimized usage (important)

```bash
./bashfuscator -c 'cat /etc/passwd' -s 1 -t 1 --no-mangling --layers 1
```

---

## 🔍 Meaning of flags

|Flag|Meaning|
|---|---|
|`-s 1`|low complexity|
|`-t 1`|minimal transformation|
|`--no-mangling`|avoids heavy random changes|
|`--layers 1`|single obfuscation layer|

---

## 🔹 Output example

```bash
eval "$(W0=(w \ t e c p s a \/ d);for Ll in ...)"
```

### What it does:

- splits command into array
    
- reconstructs it dynamically
    
- executes using `eval`
    

---

## 🔹 Testing payload

```bash
bash -c 'eval "$( ... )"'
```

### Flow:

1. `bash -c` → runs command
    
2. `eval` → reconstructs hidden command
    
3. final command executes:
    
    - `cat /etc/passwd`
        

---

# ⚠️ Why it may fail in web apps

Even if generated:

- filters may block:
    
    - `eval`
        
    - `bash`
        
    - `$()`
        
- payload may contain:
    
    - spaces
        
    - special characters
        
    - long strings (WAF limit)

# 🪟 3. Windows Tool – DOSfuscation

## 🔹 Purpose

- Same idea as Bashfuscator but for Windows
    
- Works on:
    
    - CMD
        
    - PowerShell
        

---

## 🔹 Installation

```powershell
git clone https://github.com/danielbohannon/Invoke-DOSfuscation.git
cd Invoke-DOSfuscation
Import-Module .\Invoke-DOSfuscation.psd1
Invoke-DOSfuscation
```

---

## 🔹 Help menu

Inside tool:

- `TUTORIAL` → learning mode
    
- `BINARY` → cmd/powershell obfuscation
    
- `ENCODING` → environment variable tricks
    
- `PAYLOAD` → generate obfuscated command
    

---

## 🔹 Example usage

### Set command:

```powershell
SET COMMAND type C:\Users\htb-student\Desktop\flag.txt
```

### Generate encoding:

```powershell
encoding
1
```

---

## 🔹 Output example

```cmd
typ%TEMP:~-3,-2% ...
```

### What it means:

- splits keywords using environment variables
    
- rebuilds command at runtime
    

---

## 🔹 Execution

```cmd
typ%TEMP:~-3,-2% ...
```

### Result:

```
test_flag
```
