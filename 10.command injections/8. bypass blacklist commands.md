
# **Command Injection – Bypassing Blacklisted Commands 

## **1. Concept**

- Filters may block:
    
    - Specific **words (commands)** like `whoami`, `cat`
        
- This is called:
    
    - **Command blacklist filter**
        

---

## **2. Blacklist Behavior (PHP example)**

```php
$blacklist = ['whoami', 'cat', ...SNIP...];
foreach ($blacklist as $word) {
    if (strpos($_POST['ip'], $word) !== false) {
        echo "Invalid input";
    }
}
```

### **Working**

- Checks each word in input
    
- If match found → request blocked
    

---

## **3. Key Limitation**

- Filter checks **exact words only**
    
- So slightly modified commands may bypass it
    

---

## **4. Command Obfuscation Idea**

- Modify command appearance
    
- Still executes normally in shell
    

---

## **5. Linux & Windows – Quotes Technique**

### **Single quotes**

```bash
w'h'o'am'i
```

### **Double quotes**

```bash
w"h"o"am"i
```

---

### **Rules**

- Cannot mix quote types
    
- Number of quotes must be **even**
    

---

### **Payload example**

```text
127.0.0.1%0aw'h'o'am'i
```

---

## **6. Linux-only techniques**

### **Backslash method**

```bash
w\ho\am\i
```

---

### **$@ method**

```bash
who$@ami
```

---

### **Key points**

- Works only on Linux
    
- Can use even single insertion
    
- Shell ignores these characters
    

---

## **7. Windows-only technique**

### **Caret (^) method**

```cmd
who^ami
```

---

### **Key idea**

- `^` does not affect execution
    
- Command still runs normally
