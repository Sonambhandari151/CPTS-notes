
# **Command Injection – Injecting Commands 

## **1. Starting Injection**

- Target: Host Checker web app
    
- Use **semicolon (;) operator**
    
- Payload:
    

```bash
127.0.0.1; whoami
```

---

## **2. Final Executed Command**

```bash
ping -c 1 127.0.0.1; whoami
```

---

## **3. Local Testing**

- Running in Linux:
    

```bash
ping -c 1 127.0.0.1; whoami
```

### **Result**

- Both commands executed:
    
    - `ping`
        
    - `whoami`
        
- Output shows:
    
    - Ping result
        
    - Current user
        

---

## **4. Attempt in Web Application**

- Input used:
    

```id="7wrlow"
127.0.0.1; whoami
```

### **Result**

- Input rejected
    
- Error: **“Match the requested format”**
    

---

## **5. Reason for Rejection**

- Validation happening on:
    
    - **Front-end**
        
- Evidence:
    
    - No network request sent
        
    - Checked using Developer Tools (Network tab)
        

---

## **6. Front-End Validation**

- Restricts input to:
    
    - **Valid IP format**
        
- Purpose:
    
    - Prevent malicious payloads
        

---

## **7. Limitation of Front-End Validation**

- Often:
    
    - Only front-end validation is implemented
        
    - Back-end remains unprotected
        
- Reasons:
    
    - Different development teams
        
    - Trust in front-end validation
        

---

## **8. Bypassing Front-End Validation**

- Method:
    
    - Send **custom HTTP request directly**
        
- Tool:
    
    - Web proxy (Burp Suite / ZAP)
        

---

## **9. Steps to Intercept Request**

1. Start proxy (Burp/ZAP)
    
2. Configure browser proxy
    
3. Enable intercept
    
4. Send normal request (e.g., `127.0.0.1`)
    
5. Capture request
    
6. Send to repeater (`CTRL + R`)
    

---

## **10. Modifying Request**

- Replace input with:
    

```id="r5pp9o"
127.0.0.1; whoami
```

- URL encode payload:
    
    - Shortcut: `CTRL + U`
        

---

## **11. Sending Modified Request**

- Send request via repeater
    

---

## **12. Result**

- Response includes:
    
    - Ping output
        
    - `whoami` output
