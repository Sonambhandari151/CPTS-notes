## DOM-based XSS

### Core Concept

- **Definition:** A Non-Persistent XSS type where the entire attack is processed on the **client-side**. Unlike Reflected XSS, the payload never reaches the back-end server.
    
- **Mechanism:** JavaScript execution modifies the **Document Object Model (DOM)** in the user's browser.
    
- **Detection:** Look for a hashtag (`#`) in the URL. Anything after the `#` is a fragment identifier handled strictly by the browser, not sent to the server.
    

---

### Source vs. Sink

Understanding DOM XSS requires identifying where data enters and where it is executed.

- **Source:** The JavaScript object that accepts user input.
    
    - _Examples:_ `location.search`, `document.URL`, `location.hash`.
        
- **Sink:** The execution point or function that writes the input to the page.
    
    - _Dangerous Sinks:_ `innerHTML`, `outerHTML`, `document.write()`.
        
    - _jQuery Sinks:_ `.add()`, `.append()`, `.after()`.
        

---

### Key Characteristics

1. **Invisible in Source Code:** If you press `CTRL+U` (View Page Source), the payload will **not** be there because the DOM is updated dynamically _after_ the page loads.
    
2. **Visible in Inspector:** You must use the Web Inspector (`CTRL+SHIFT+C`) to see the rendered HTML containing the payload.
    
3. **Non-Persistent:** The payload is lost upon refreshing the page unless triggered again by the specific URL.
    

---

### Bypassing `innerHTML` Restrictions

Modern browsers prevent `<script>` tags from executing when injected via `innerHTML`. To exploit this, use "event-based" payloads:

- **The `onerror` Payload:**
    
    HTML
    
    ```
    <img src="" onerror=alert(window.origin)>
    ```
    
    - **How it works:** The browser tries to load an empty image string, fails, and immediately triggers the `onerror` JavaScript event.
        

---

### Example Workflow

1. **Identify the Source:** Script reads from URL: `var task = document.URL.substring(...)`.
    
2. **Identify the Sink:** Script writes to page: `document.getElementById("todo").innerHTML = task`.
    
3. **Inject:** Use a non-script payload in the URL: `http://IP:PORT/#task=<img src="" onerror=alert(1)>`.
