##  1. What are Type Filters?

Earlier filters only checked:

- ❌ file extension (e.g., `.jpg`, `.php`)
    

Now modern systems also check:

-  file type (what the file actually is)
    

So even if you rename:

```id="u8k1pz"
shell.php.jpg
```

it may still get blocked.

---

#  2. Why extension filters are weak

Extension-only checks are unsafe because:

- You can rename files (`.php.jpg`)
    
- Server may misinterpret extensions
    
- Some allowed formats (like SVG) can still be exploited
    

 So extension ≠ real security

---

# 🧪 3. Two MAIN content-based filters

Modern systems check file type using:

## (A) Content-Type Header

## (B) MIME Type (File content)

---

#  4. Content-Type Header Filter

##  What it is

Browser sends:

```id="x4p9n2"
Content-Type: image/png
```

Server checks:

> “Is this an allowed type?”

---

##  Key weakness

- This header is sent by **client (browser)**
    
- So attacker can modify it using Burp Suite
    

---

##  Example bypass idea

Change:

```id="7v3m1a"
Content-Type: application/x-php ❌
```

To:

```id="m2q8lz"
Content-Type: image/jpeg ✔
```

---

##  Server-side check example

```php
$type = $_FILES['uploadFile']['type'];

if (!in_array($type, ['image/jpg','image/png'])) {
    die("Only images allowed");
}
```

 It trusts browser input → weak security

---

#  5. MIME Type (File Content Check)

##  What it is

Instead of trusting headers, server checks:

> “What is actually inside the file?”

It reads:

- first bytes of file (magic bytes / signature)
    

---

##  Example magic bytes

| File Type | Starts With      |
| --------- | ---------------- |
| GIF       | GIF87a / GIF89a  |
| PNG       | binary signature |
| JPG       | binary signature |

---

##  Example trick

Normal file:

```id="8nq5kd"
text.jpg → ASCII text ❌
```

Fake GIF header:

```id="p7w2sm"
GIF8 + PHP code → treated as image ✔
```

---

##  Why GIF is commonly used

Because:

- starts with readable text (`GIF8`)
    
- easy to prepend
    
- works in many labs
    

---

#  Example server check (PHP)

```php
$type = mime_content_type($_FILES['uploadFile']['tmp_name']);

if (!in_array($type, ['image/jpg','image/png'])) {
    die("Only images allowed");
}
```

 Now server checks real file content, not filename

---

#  6. Bypass strategy summary

## If extension filter exists:

Try:

- `shell.php.jpg`
    
- `shell.jpg.php`
    

---

## If Content-Type filter exists:

Modify header:

- `image/jpeg`
    
- `image/png`
    

---

## If MIME filter exists:

Modify file content:

- Add magic bytes (e.g. `GIF8`)
    
- Still include PHP code after it
    

---

#  7. Combining attacks (important concept)

Real CTF logic:

You mix mismatches:

| Check        | Trick              |
| ------------ | ------------------ |
| Extension    | fake `.jpg`        |
| Content-Type | spoof image header |
| MIME type    | fake magic bytes   |
