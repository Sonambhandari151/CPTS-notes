
---

## 1. What is blacklist validation?

- Backend checks uploaded file extensions against a **blocked list**
    
- Example:
    
    - `.php`, `.php7`, `.phps` → blocked
        
- If match found → upload rejected
    

---

## 2. Example backend logic

```php
$fileName = basename($_FILES["uploadFile"]["name"]);
$extension = pathinfo($fileName, PATHINFO_EXTENSION);

$blacklist = array('php', 'php7', 'phps');

if (in_array($extension, $blacklist)) {
    echo "File type not allowed";
    die();
}
```

### What it does:

- Extracts file extension
    
- Compares with blacklist
    
- Blocks if match found
    

---

## 3. Weakness of blacklist filters

Blacklist is **incomplete by design**:

- Cannot include every dangerous extension
    
- Misses alternative execution formats
    
- Often case-sensitive
    
- Different server configs behave differently
    

---

## 4. Case sensitivity issue

- Filter checks only lowercase
    
- Server may accept:
    
    - `pHp`
        
    - `PhP`
        
- On Windows systems → case-insensitive execution possible
    

---

## 5. Fuzzing extensions (discovery method)

Purpose:

- Find allowed file extensions bypassing blacklist
    

### Process:

- Intercept upload request in Burp
    
- Send to Intruder
    
- Replace extension position
    
- Test many extensions list
    

### Observation:

- Some responses = **"File successfully uploaded"**
    
- Others = **"Extension not allowed"**
    

---

## 6. Key result of fuzzing

- Extensions that return success are **not blocked**
    
- These become potential exploitation targets
    

---

## 7. Non-blacklisted executable extensions

Even if `.php` is blocked, others may work depending on server config:

Examples:

- `.phtml`
    
- `.php5`
    
- `.php7`
    
- `.phar`
    

---

## 8. Why `.phtml` works

- Treated as PHP executable by many Apache/PHP configs
    
- Bypasses simple blacklist filters
    

---

## 9. Exploitation flow

1. Find allowed extension via fuzzing
    
2. Upload PHP web shell using allowed extension
    
3. Access uploaded file in browser
    
4. Execute commands:
    

```id="k3m9vx"
?cmd=id
```

or

```id="f9x2la"
?cmd=cat /flag.txt
```

---

## 10. Key limitation of blacklist filtering

- It is **reactive**, not secure
    
- Attackers always find:
    
    - missed extensions
        
    - encoding tricks
        
    - alternate execution formats
