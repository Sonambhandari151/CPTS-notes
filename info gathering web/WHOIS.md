
# 📘 **WHOIS (Overview)**

👉 WHOIS is a **query protocol** used to get information about:

- Domain names
    
- IP addresses
    
- Autonomous systems
    

💡 Think of it as an **internet phonebook**

---

# 🔹 **Information in WHOIS Record**

- **Domain Name** → e.g., example.com
    
- **Registrar** → company (GoDaddy, Namecheap)
    
- **Registrant Contact** → owner details
    
- **Admin Contact** → domain manager
    
- **Technical Contact** → technical handler
    
- **Creation Date** → when registered
    
- **Expiry Date** → when it ends
    
- **Name Servers** → DNS servers
    

---

# 🔹 **History (Important)**

- Developed in **1970s (ARPANET era)**
    
- Created by **Elizabeth Feinler**
    
- Managed by **Network Information Center (NIC)**
    

---

# 🔹 **Why WHOIS is Important in Recon**

### 🎯 1. Identify People

- Names, emails, phone numbers
    
- Useful for **social engineering / phishing**
    

---

### 🌐 2. Network Info

- Name servers
    
- IP infrastructure  
    👉 Helps find **entry points**
    

---

### 📊 3. Historical Analysis

- Ownership changes
    
- Old configurations  
    👉 Useful for **tracking target evolution**
    

---

# 🔹 **Command Example**

```bash
whois example.com
```

---

# ⚠️ **Key Point**

- WHOIS is **passive reconnaissance**
    
- Very **low detection risk**
