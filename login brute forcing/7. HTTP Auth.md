## Basic HTTP Authentication: Concepts and Exploitation

Basic HTTP Authentication is one of the simplest methods used by web servers to restrict access to resources. While easy to set up, it is highly vulnerable to brute-force attacks because it lacks built-in protections like account lockouts or rate-limiting.

---

### 1. How Basic Auth Works

Basic Auth is a **challenge-response** mechanism. The interaction follows these steps:

1. **Request:** A user attempts to access a protected URL (e.g., `/admin`).
    
2. **Challenge:** The server responds with an **HTTP 401 Unauthorized** status and a `WWW-Authenticate: Basic` header.
    
3. **Prompt:** The browser displays a native login dialog to the user.
    
4. **Submission:** The browser combines the username and password with a colon (`user:pass`), encodes it in **Base64**, and sends it in the `Authorization` header.
    
    - _Example:_ `alice:secret123` becomes `YWxpY2U6c2VjcmV0MTIz`.
        
5. **Verification:** The server decodes the string and grants access if the credentials match.
    

---

### 2. Exploiting Basic Auth with Hydra

Because the credentials are sent in every request header, Hydra can rapidly test thousands of combinations by sending multiple GET requests with different `Authorization` headers.

#### The Scenario

- **Target:** A web server at a specific IP.
    
- **Known Username:** `basic-auth-user`.
    
- **Port:** 81 (non-standard).
    
- **Goal:** Find the password to retrieve a flag.
    

#### Step-by-Step Attack Execution

**Step 1: Prepare the Wordlist**

Download a targeted list of common passwords (e.g., from SecLists).

Bash

```
curl -s -O https://raw.githubusercontent.com/danielmiessler/SecLists/master/Passwords/2023-200_most_used_passwords.txt
```

**Step 2: Run Hydra**

Use the `http-get` module, which is specifically designed for Basic Auth over the GET method.

Bash

```
hydra -l basic-auth-user -P 2023-200_most_used_passwords.txt <TARGET_IP> http-get / -s 81
```

**Command Breakdown:**

- `-l basic-auth-user`: Sets the static username.
    
- `-P [file]`: Points to the password wordlist.
    
- `<TARGET_IP>`: The IP address of your spawned HTB instance.
    
- `http-get /`: Targets the root directory using the HTTP GET method.
    
- `-s 81`: Tells Hydra to look at port 81 instead of the default port 80.
