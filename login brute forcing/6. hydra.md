## Hydra: The Fast Network Login Cracker

Hydra is a high-speed, parallelized network login cracker that supports a vast array of protocols. It is a staple tool in penetration testing due to its ability to attack multiple services—from web forms and SSH to databases and mail servers—simultaneously.

---

### 1. Key Features of Hydra

- **Parallelization:** Uses multiple "tasks" (threads) to attempt several logins at once, making it much faster than sequential scripts.
    
- **Protocol Support:** Compatible with over 50 protocols (SSH, FTP, HTTP, MySQL, MSSQL, RDP, etc.).
    
- **Customization:** Supports specific service options, non-standard ports, and custom success/failure triggers.
    

---

### 2. Basic Command Syntax

Bash

```
hydra [login_options] [password_options] [attack_options] [service_options]
```

#### Common Parameters

|**Parameter**|**Description**|**Example**|
|---|---|---|
|`-l` / `-L`|Single username / **L**ist of usernames.|`-l admin` or `-L users.txt`|
|`-p` / `-P`|Single password / **P**assword list.|`-p 12345` or `-P rockyou.txt`|
|`-t`|Number of parallel threads (default is 16).|`-t 4`|
|`-s`|Non-standard port.|`-s 2222`|
|`-f`|**F**inish after the first valid pair is found.|`-f`|
|`-v` / `-V`|**V**erbose / Show attempts as they happen.|`-V`|
|`-M`|File containing a list of target IPs/Hosts.|`-M targets.txt`|
|`-x`|**Generate** passwords (min:max:charset).|`-x 4:6:a1`|

---

### 3. Service-Specific Examples

#### A. SSH (Standard Port)

Bash

```
hydra -l root -P passwords.txt 192.168.1.100 ssh
```

#### B. FTP (Non-Standard Port with Verbosity)

Bash

```
hydra -L users.txt -P passwords.txt -s 2121 -V ftp.example.com ftp
```

#### C. Web Login Form (HTTP-POST)

When targeting web forms, you must specify the URL path, the form parameters, and a condition that indicates a failed or successful login (e.g., `F=incorrect` or `S=302`).

Bash

```
hydra -l admin -P passwords.txt www.example.com http-post-form "/login:user=^USER^&pass=^PASS^:S=302"
```

#### D. Remote Desktop (RDP) with Generation

If you don't have a wordlist, you can generate combinations on the fly.

Bash

```
hydra -l administrator -x 6:8:aA1 192.168.1.100 rdp
```

### 5. Pentester's Pro-Tips

- **Thread Management:** While higher threads (`-t`) increase speed, they can crash the service or trigger rate-limiting defenses. Start with `-t 4` and increase slowly.
    
- **The `-f` Flag:** Always use the `-f` flag during real engagements to stop as soon as you get a hit, reducing unnecessary noise on the network.
    
- **Success Triggers:** For web forms, carefully check if the site uses a redirect (`S=302`) or a specific error message (`F=Login Failed`) to ensure Hydra correctly identifies a successful attempt.
