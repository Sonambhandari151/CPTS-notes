## Medusa: Parallel Login Brute-Forcer

### Core Functionality

- **Purpose:** Fast, modular, parallel authentication testing.
    
- **Key Feature:** Supports multiple protocols (SSH, FTP, HTTP, MySQL, etc.) via independent modules.
    

### Installation

- **Check version:** `medusa -h`
    
- **Install (Debian/Ubuntu):** `sudo apt-get install medusa`
    

---

### Command Syntax

`medusa [target] [credentials] -M [module] [options]`

|**Flag**|**Parameter**|**Example**|
|---|---|---|
|**-h / -H**|Target IP / Host list file|`-h 192.168.1.1`|
|**-u / -U**|Single username / User list file|`-U users.txt`|
|**-p / -P**|Single password / Pass list file|`-P rockyou.txt`|
|**-M**|Service Module|`-M ssh`|
|**-m**|Module-specific options|`-m DIR:/admin`|
|**-n**|Non-default port|`-n 2222`|
|**-t**|Parallel tasks (threads)|`-t 10`|
|**-f**|Stop after first success|`-f`|
|**-e ns**|Check Null (n) and Same (s) passwords|`-e ns`|
|**-v**|Verbosity level (1-6)|`-v 4`|

---

### Common Usage Scenarios

- **SSH Brute Force:**
    
    `medusa -h 192.168.0.100 -U users.txt -P pass.txt -M ssh`
    
- **HTTP Basic Auth (Multiple Targets):**
    
    `medusa -H targets.txt -U users.txt -P pass.txt -M http -m GET`
    
- **Web Form (POST):**
    
    `medusa -M web-form -h example.com -m FORM:"user=^USER^&pass=^PASS^:F=Invalid"`
    
- **Default Credential Check:**
    
    `medusa -h 10.0.0.5 -U users.txt -e ns -M ftp`
