# ColdFusion Exploitation Notes

## Section 1 — ColdFusion: Discovery & Enumeration

### 1.1 What Is ColdFusion?
ColdFusion is a Java-based web application platform created by Allaire (1995), acquired by Macromedia (2001), then Adobe. It uses **CFML** (ColdFusion Markup Language) — tag-based, HTML-like syntax for DB integration, web services, email, etc.

> [!tip] Exam tip
> `<cfquery>` executes SQL. `<cfloop>` iterates query results. CFML can embed JavaScript/Java.

**CFML example:**
```cfml
<cfquery name="myQuery" datasource="myDataSource">
  SELECT *
  FROM myTable
</cfquery>

<cfloop query="myQuery">
  <p>#myQuery.firstName# #myQuery.lastName#</p>
</cfloop>
```

### 1.2 Key Benefits
| Benefit | Description |
|---|---|
| Rapid data-driven apps | Session mgmt, form handling, built-in debugging |
| Database integration | Native connectivity to Oracle, MSSQL, MySQL |
| Web content management | Dynamic HTML, URL rewriting, uploads, AJAX serialization |
| Performance | Optimised for low latency, high concurrency |
| Collaboration | Code sharing, version control, real-time collab |

### 1.3 Version History & Known CVEs
Latest stable (at writing): CF2021, CF2023 entering Alpha. Earlier: 2018, 2016, 11.

### 1.4 Default Ports
| Port | Protocol | Purpose |
|---|---|---|
| 80 | HTTP | Non-secure web traffic |
| 443 | HTTPS | Encrypted web traffic |
| 1935 | RPC | Client–server RPC |
| 25 | SMTP | Outbound email |
| **8500** | SSL | Default CF admin/app port — **key fingerprint** |
| 5500 | Server Monitor | Remote administration |

> [!important] Remember
> Port 8500 is the strongest CF fingerprint — non-standard enough that seeing it open should immediately trigger CF-specific enumeration.

### 1.5 Enumeration Methods
| Method | What to Look For |
|---|---|
| Port scanning | 80/443, notably 8500; Nmap may fingerprint CF directly |
| File extensions | `.cfm` / `.cfc` in URLs |
| HTTP headers | `Server: ColdFusion` / `X-Powered-By: ColdFusion` |
| Error messages | Errors referencing CF tags/functions |
| Default files | `/CFIDE/administrator/index.cfm`, `admin.cfm` |

### 1.6 Practical Walkthrough

**Step 1 — Full port scan**
```bash
nmap -p- -sC -Pn 10.129.247.30 --open

PORT      STATE SERVICE
135/tcp   open  msrpc
8500/tcp  open  fmtp
49154/tcp open  unknown
```
Port 8500 open → strong CF indicator. RPC ports → Windows host.

**Step 2 — Browse the web root**
- `https://<target>:8500/` → shows `CFIDE` and `cfdocs` dirs
- `/CFIDE/` listing → `Application.cfm`, `adminapi/`, `install.cfm`
- Triggering an error leaks CF-specific debug info

**Step 3 — Confirm version via admin login**
- `/CFIDE/administrator/` → CF Administrator login page
- Page branding confirms exact major version (here: **CF8**)
