

## Jenkins Overview

- **Definition:** An open-source, Java-based automation server used for continuous project building and testing.
    
- **History:** Released in 2005 as _Hudson_; renamed to _Jenkins_ in 2011 after an Oracle dispute.
    
- **Prevalence:** Utilized by over 86,000 companies, including Facebook, Netflix, and LinkedIn.
    

## Discovery & Footprinting

- **Target Value:** Frequently installed on Windows servers under high-privilege **SYSTEM accounts**, offering an ideal foothold into Active Directory.
    
- **Default Ports:** Runs on web port **8080** by default, and uses port **5000** for master-to-slave server communication.
    
- **Authentication Options:** Supports local databases, LDAP, Unix user databases, servlet delegation, or running with no authentication at all.
    

## Enumeration

- **Fingerprinting:** Quickly identified via its distinctive web login page layout.
    
- **Default Behavior:** Typically blocks public registration and defaults to an internal credential database.
    
- **Common Weakness:** Frequently found completely unauthenticated or secured with weak, default credentials like `admin:admin`.
