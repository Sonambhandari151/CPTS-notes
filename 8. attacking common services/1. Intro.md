## Interacting with Common Services – 

### 1. Overview of File Share Services

File sharing services allow users/systems to **store, access, and transfer files over a network**.

They can be:

- **Internal services (on local network):**
    
    - SMB (Windows)
        
    - NFS (Linux)
        
    - FTP / TFTP / SFTP
        
- **Cloud services (external/modern):**
    
    - Google Drive, Dropbox, OneDrive
        
    - AWS S3, Azure Blob Storage, Google Cloud Storage
        

In security work, we often interact with both internal and cloud-based file shares to:

- Find sensitive files
    
- Enumerate data
    
- Extract credentials or configuration files
    

---

## 2. SMB (Server Message Block)

### What is SMB?

SMB is a **network file-sharing protocol mainly used in Windows environments**.

It allows:

- Sharing files and folders
    
- Accessing remote directories
    
- Managing permissions across networks
    

---

## 3. Accessing SMB in Windows

### A. GUI Method

You can access SMB using Run dialog:

```
\\192.168.220.129\Finance\
```

Steps:

1. Press `WIN + R`
    
2. Enter SMB path
    
3. If allowed → folder opens directly
    
4. If not → authentication prompt appears
    

---

### B. CMD (Command Prompt) Methods

#### 1. Listing SMB Share Content

```cmd
dir \\192.168.220.129\Finance\
```

Explanation:

- `dir` → lists files and directories
    
- UNC path (`\\IP\share`) → remote SMB location
    

Output shows folders/files available in the share.

---

#### 2. Mapping SMB Share to Drive

```cmd
net use n: \\192.168.220.129\Finance
```

Explanation:

- `net use` → connects network resource
    
- `n:` → mapped drive letter
    
- After mapping, SMB behaves like local drive
    

---

#### 3. Authentication with Username/Password

```cmd
net use n: \\192.168.220.129\Finance /user:plaintext Password123
```

- Used when share requires credentials
    
- `/user:` specifies username
    
- Password follows username
    

---

#### 4. Counting Files in SMB Share

```cmd
dir n: /a-d /s /b | find /c ":\"
```

Breakdown:

|Part|Meaning|
|---|---|
|`dir n:`|lists drive contents|
|`/a-d`|excludes directories|
|`/s`|includes subdirectories|
|`/b`|bare format (only paths)|
|`|`|
|`find /c`|counts lines containing pattern|

Result: total number of files in share.

---

#### 5. Searching for File Names

```cmd
dir n:\*cred* /s /b
```

Finds files containing “cred” in name.

Examples:

- credentials.txt
    
- secret_cred.doc
    

---

#### 6. Searching Inside Files

```cmd
findstr /s /i cred n:\*.*
```

Explanation:

|Option|Meaning|
|---|---|
|`findstr`|searches text inside files|
|`/s`|recursive search|
|`/i`|case-insensitive|
|`cred`|search keyword|
|`n:\*.*`|all files|

Output shows matching lines inside files.

---

## 4. PowerShell SMB Interaction

PowerShell is more powerful than CMD because it uses **cmdlets (structured commands)**.

---

### A. Listing SMB Share

```powershell
Get-ChildItem \\192.168.220.129\Finance\
```

- Equivalent to `dir`
    
- Shows directory contents in structured format
    

---

### B. Mapping SMB Drive

```powershell
New-PSDrive -Name "N" -Root "\\192.168.220.129\Finance" -PSProvider "FileSystem"
```

Explanation:

- `New-PSDrive` → creates mapped drive
    
- `-Name` → drive letter
    
- `-Root` → SMB path
    
- `-PSProvider FileSystem` → treats as file system
    

---

### C. Authentication using Credentials

Step 1: Create variables

```powershell
$username = 'plaintext'
$password = 'Password123'
```

Step 2: Convert password securely

```powershell
$secpassword = ConvertTo-SecureString $password -AsPlainText -Force
```

Step 3: Create credential object

```powershell
$cred = New-Object System.Management.Automation.PSCredential $username, $secpassword
```

Step 4: Map drive with credentials

```powershell
New-PSDrive -Name "N" -Root "\\192.168.220.129\Finance" -PSProvider "FileSystem" -Credential $cred
```

---

### D. Counting Files

```powershell
(Get-ChildItem -File -Recurse | Measure-Object).Count
```

Explanation:

- `Get-ChildItem` → list files
    
- `-Recurse` → include subfolders
    
- `Measure-Object` → counts items
    

---

### E. Searching Files by Name

```powershell
Get-ChildItem -Recurse -Path N:\ -Include *cred* -File
```

- Finds files with “cred” in filename
    

---

### F. Searching File Content

```powershell
Get-ChildItem -Recurse -Path N:\ | Select-String "cred" -List
```

Explanation:

- `Select-String` → PowerShell version of grep/findstr
    
- Searches inside file contents
    

---

## 5. Linux SMB Interaction

Linux uses **CIFS (Common Internet File System)** to mount SMB shares.

---

### A. Mount SMB Share

```bash
sudo mkdir /mnt/Finance
sudo mount -t cifs -o username=plaintext,password=Password123,domain=. //192.168.220.129/Finance /mnt/Finance
```

Explanation:

|Part|Meaning|
|---|---|
|`mount`|attach remote filesystem|
|`-t cifs`|SMB protocol type|
|`-o`|options|
|`username/password`|authentication|
|`//IP/share`|SMB path|
|`/mnt/Finance`|local mount point|

---

### B. Using Credential File (safer method)

Mount command:

```bash
mount -t cifs //192.168.220.129/Finance /mnt/Finance -o credentials=/path/credentialfile
```

Credential file format:

```txt
username=plaintext
password=Password123
domain=.
```

---

### C. Searching Files in Linux

#### Find file names:

```bash
find /mnt/Finance/ -name *cred*
```

- Searches filenames only
    

---

#### Search inside files:

```bash
grep -rn /mnt/Finance/ -ie cred
```

Explanation:

|Option|Meaning|
|---|---|
|`grep`|text search tool|
|`-r`|recursive|
|`-n`|line numbers|
|`-i`|case-insensitive|
|`-e`|pattern|

# 1. Other File Sharing Services (FTP, TFTP, NFS)

Apart from SMB, there are other file-sharing protocols:

### Common Services:

- **FTP (File Transfer Protocol)**
    
- **TFTP (Trivial FTP)**
    
- **NFS (Network File System)**
    

### Key Idea:

- These services allow **file transfer or remote file mounting**
    
- Once mounted/connected, we can use normal OS tools:
    
    - `ls`, `find`, `grep` (Linux)
        
    - `dir`, `findstr` (Windows)
        

### Important Concept:

- Every service behaves differently
    
- We must learn:
    
    - How it works
        
    - Which tools interact with it
        
    - Authentication methods

# 2. Email Services

Email communication uses **two main protocol types**:

### Core Protocols:

- **SMTP (Simple Mail Transfer Protocol)** → sending emails
    
- **POP3 / IMAP** → receiving emails
    

---

## 2.1 Email Flow

|Action|Protocol|
|---|---|
|Send email|SMTP|
|Receive email|POP3 or IMAP|

---

## 2.2 Email Client Example (Evolution)

Evolution is a Linux email client.

### Install Evolution:

```bash
sudo apt-get install evolution
```

### Fix startup error (if occurs):

```bash
export WEBKIT_FORCE_SANDBOX=0 && evolution
```

---

## 2.3 Email Server Connection

When connecting to email servers:

- Use **IP or domain name**
    
- Choose correct protocol:
    
    - SMTP / SMTPS (sending)
        
    - IMAP / IMAPS (receiving)
        

### Secure options:

- **TLS encryption**
    
- **STARTTLS upgrade after connection**
    

---

## 2.4 Server Authentication Check

- Clients often have option:
    
    - “Check supported authentication types”
        
- Helps verify:
    
    - login method
        
    - encryption support
