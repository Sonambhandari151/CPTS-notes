## 🔸 SMB Enumeration

| Purpose                    | Command                                |
| -------------------------- | -------------------------------------- |
| List shares (null session) | `smbclient -N -L //<IP>/`              |
| List shares (with creds)   | `smbclient -L //<IP>/ -U username`     |
| Access share               | `smbclient //<IP>/<share> -U username` |

---

## 🔸 smbmap 

| Purpose                   | Command                                                        |
| ------------------------- | -------------------------------------------------------------- |
| List shares + permissions | `smbmap -H <IP>`                                               |
| With credentials          | `smbmap -H <IP> -u <user> -p <pass>`                           |
| Recursive listing         | `smbmap -H <IP> -r <share>`                                    |
| Download file             | `smbmap -H <IP> --download "<share>/<file>"`                   |
| Upload file               | `smbmap -H <IP> --upload <local_file> "<share>/<remote_file>"` |

✔ Example:  
`sudo smbmap -H 10.10.10.10 --download "notes/note.txt"`
