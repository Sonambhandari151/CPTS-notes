# **Attacking DNS – Notes**

## **1. DNS Basics**

- DNS = converts:
    
    ```
    domain → IP address
    ```
    
- Example:
    
    ```
    hackthebox.com → 104.17.42.72
    ```
    
- Uses:
    
    - **UDP/53 (default)**
        
    - **TCP/53 (when large data / zone transfer)**
        

---

## **2. Importance**

- Used by **almost all network applications**
    
- Attacks on DNS = **major threat**
    

---

# **3. Enumeration**

## **Nmap Enumeration**

```bash
nmap -p53 -Pn -sV -sC 10.10.110.213
```

### **Purpose**

- Check DNS service
    
- Identify:
    
    - Version
        
    - Running service
        

---

# **4. DNS Zone Transfer**

## **Concept**

- DNS zone = part of DNS database
    
- Used to **share data between DNS servers**
    

### **Important Point**

- No authentication required (if misconfigured)
    
- Uses:
    
    - **TCP port 53**
        

---

## **Attack Impact**

- Attacker gets:
    
    - Full DNS records
        
    - Subdomains
        
    - Internal structure
        

---

## **DIG Command**

```bash
dig AXFR @ns1.inlanefreight.htb inlanefreight.htb
```

### **Purpose**

- Dump entire DNS zone
    

---

# **5. Fierce Tool**

fierce --domain zonetransfer.me

### **Purpose**

- Find DNS servers
    
- Check zone transfer vulnerability
    

---

# **6. Domain Takeover**

## **Concept**

- Register an **expired domain**
    
- Gain control over it
    

---

# **7. Subdomain Takeover**

## **Concept**

- Happens due to **CNAME records**
    

```bash
sub.target.com → anotherdomain.com
```

### **Condition**

- If `anotherdomain.com` expires:
    
    - Attacker registers it
        
    - Gains control over `sub.target.com`
        

---

### **Purpose**

- Brute-force subdomains
    
- Works without internet

```

```
support.inlanefreight.com → AWS S3

    - Vulnerable to takeover

# **9. DNS Spoofing (Cache Poisoning)**

## **Concept**

- Modify DNS records
    
- Redirect user to fake site
    

---

## **Attack Methods**

- MITM attack
    
- DNS server vulnerability
    

---

# **10. Local DNS Cache Poisoning**

## **Ettercap Setup**

### **Step 1: Edit DNS file**

```bash
/etc/ettercap/etter.dns
```

```
inlanefreight.com      A   192.168.225.110
*.inlanefreight.com    A   192.168.225.110
```

---

### **Step 2: Select Targets**

- Target1 → Victim IP
    
- Target2 → Gateway
    

---

### **Step 3: Enable Plugin**

- `dns_spoof`
    

---

## **Result**

- Victim visits:
    
    ```
    inlanefreight.com
    ```
    
- Redirected to:
    
    ```
    192.168.225.110 (attacker)
    ```
    

---

## **Verification**

```cmd
ping inlanefreight.com
```

### **Output**

```
Resolved IP = attacker IP
```
