# Important Notes

- Logrotate automatically manages Linux log files.
    
- Prevents logs from consuming full disk space.
    
- Usually runs periodically using cron jobs.
    
- Main configuration:
    

```bash
/etc/logrotate.conf
```

- Service-specific configurations:
    

```bash
/etc/logrotate.d/
```

- Rotation tracking file:
    

```bash
/var/lib/logrotate.status
```

- Exploitation requirements:
    
    - Writable log file
        
    - Logrotate running as root
        
    - Vulnerable version installed
        
- `create` creates a new empty log after rotation.
    
- `compress` compresses rotated logs.
    
- `delaycompress` delays compression until next cycle.
    
- Common vulnerable condition:
    
    - Writable log rotated by root.
