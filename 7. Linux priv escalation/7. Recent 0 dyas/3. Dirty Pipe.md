# Dirty Pipe (CVE-2022-0847)

## Vulnerability

Type:

> Linux kernel privilege escalation vulnerability

Name:

> Dirty Pipe

CVE:

> CVE-2022-0847

---

# Affected Kernels

```bash
5.8 → 5.17
```

Check kernel:

```bash
uname -r
```

Example:

```bash
5.13.0-46-generic
```

Meaning:

> vulnerable kernel.

---

# What Vulnerability Does

Allows:

> writing to root-owned read-only files.

Requirement:

> only read permission needed.

Result:

> privilege escalation to root.

---

# Based On

Uses:

> Linux pipes.

Pipe:

> communication channel between processes.

# Exploit 1 — Modify /etc/passwd

Purpose:

> set root password.

Run:

```bash
./exploit-1
```

---

# What It Does

1. Backup `/etc/passwd`
    
2. Change root password
    
3. Restore passwd file
    
4. Spawn root shell
    

---

# Example Output
