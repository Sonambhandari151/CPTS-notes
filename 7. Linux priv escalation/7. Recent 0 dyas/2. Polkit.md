# Polkit (PolicyKit)

Purpose:

> Authorization manager in Linux.

Controls:

- what actions users/programs can perform
    
- whether admin privileges are required
    

Acts like:

> security checker between applications and system services.

---

# Example Flow

User/application requests privileged action

↓

Polkit checks:

- allowed?
    
- denied?
    
- need admin authentication?
    

↓

Action executed or blocked.

---

# Main Polkit Directories

|Path|Purpose|
|---|---|
|`/usr/share/polkit-1/actions`|policy/action files|
|`/usr/share/polkit-1/rules.d`|rule files|
|`/etc/polkit-1/localauthority/50-local.d`|custom local rules|
- Custom rules can be placed in the directory `/etc/polkit-1/localauthority/50-local.d` with the file extension `.pkla`.

---

# Important Polkit Tools

| Tool       | Use                                                                        |
| ---------- | -------------------------------------------------------------------------- |
| `pkexec`   | run command as another user/root                                           |
| `pkaction` | can be used to display actions                                             |
| `pkcheck`  | this can be used to check if a process is authorized for a specific action |

---

# pkexec

Syntax:

```bash
pkexec -u <user> <command>
```

Example:

```bash
pkexec -u root id
```

Use:

> run command as root.

---

# Output

```bash
uid=0(root)
```

Meaning:

> command executed as root.

---

# CVE-2021-4034 (PwnKit)

Component:

```bash
pkexec
```

Type:

> memory corruption vulnerability.

Impact:

> local privilege escalation to root.
