## Linux Privilege Escalation Enumeration Cheat Sheet

|Command|Purpose|
|---|---|
|`uname -a`|Show kernel and system information|
|`cat /etc/os-release`|Show Linux distribution/version|
|`hostnamectl`|Detailed host and OS info|
|`id`|Show current user UID/GID/groups|
|`whoami`|Show current username|
|`sudo -l`|Show sudo privileges|
|`ps aux`|Show all running processes|
|`ps au`|Show terminal-attached processes|
|`netstat -tulpn`|Show listening ports/services|
|`ss -tulpn`|Modern alternative to netstat|
|`systemctl list-units --type=service`|List services|
|`ls /home`|List user home directories|
|`ls -la /home/user`|Show hidden files in user directory|
|`history`|Show bash history|
|`cat ~/.bash_history`|Read shell history file|
|`ls -la ~/.ssh`|Check SSH keys|
|`find / -name id_rsa 2>/dev/null`|Find private SSH keys|
|`cat /etc/passwd`|List users|
|`cat /etc/shadow`|View password hashes (if readable)|
|`find / -perm -4000 2>/dev/null`|Find SUID binaries|
|`find / -perm -2000 2>/dev/null`|Find SGID binaries|
|`crontab -l`|Show current user cron jobs|
|`ls -la /etc/cron*`|List system cron jobs|
|`find / -writable -type d 2>/dev/null`|Find writable directories|
|`find / -writable -type f 2>/dev/null`|Find writable files|
|`lsblk`|Show disks and partitions|
|`mount`|Show mounted filesystems|
|`df -h`|Show disk usage|
|`env`|Show environment variables|
|`getcap -r / 2>/dev/null`|Find Linux capabilities|
|`find / -path /proc -prune -o -type d -perm -o+w 2>/dev/null`|Find world-writable directories|
|`find / -path /proc -prune -o -type f -perm -o+w 2>/dev/null`|Find world-writable files|

# Important Notes

## 1. Enumeration is the Key

- First step after getting shell access.
    
- Goal: gather information for privilege escalation paths.
    

Main things to enumerate:

- OS version
    
- Kernel version
    
- Running services
    
- Users
    
- Sudo privileges
    
- Writable files/directories
    
- SUID binaries
    
- Cron jobs
    
- SSH keys
    
- Installed packages

# OS & Kernel Enumeration

## Check OS Version

```bash
cat /etc/os-release
```

Purpose:

- Identify distro/version.
    
- Look for public exploits.
    

Example:

- Ubuntu 18.04
    
- Debian 10
    
- CentOS 7
    

---

## Check Kernel Version

```bash
uname -a
```

Purpose:

- Kernel exploits may exist for specific versions.
    

Warning:

- Kernel exploits can crash systems.

# Process Enumeration

## List All Processes

```bash
ps aux
```

Breakdown:

- `a` → all users
    
- `u` → user-oriented format
    
- `x` → processes without terminal
    

Used to:

- Find services running as root
    
- Detect vulnerable services
    

Example:

```bash
ps aux | grep root
```

Find processes running as root.

---

## List Terminal Processes

```bash
ps au
```

Difference:

- No `x`
    
- Shows only terminal-attached processes.
    

Useful for:

- Seeing logged-in users.
    
- Detecting active admin sessions.
    

---

# User Enumeration

## List Users

```bash
cat /etc/passwd
```

Important fields:

```text
username:x:UID:GID:comment:home:shell
```

Example:

```text
root:x:0:0:root:/root:/bin/bash
```

Things to look for:

- Users with shell access
    
- Service accounts
    
- Password hashes directly inside `/etc/passwd`
    

---

## Current User Info

```bash
id
```

Shows:

- UID
    
- GID
    
- Groups
    

Important:

- Group memberships may give privileges.

# Sudo Privileges

## Check Sudo Access

```bash
sudo -l
```

Example:

```text
(root) NOPASSWD: /usr/sbin/tcpdump
```

Meaning:

- User can run `tcpdump` as root without password.
    

Important:

- Check GTFOBins for privilege escalation.

# Cron Jobs

## List Cron Jobs

```bash
ls -la /etc/cron*
```

Purpose:

- Find scheduled tasks running as root.
    

Look for:

- Writable scripts
    
- Relative paths
    
- Weak permissions
    

Example:

```bash
-rwx--x--x 1 root root 379 Aug 30 23:49 backup
```

# Writable Directories

## Find World-Writable Directories

```bash
find / -path /proc -prune -o -type d -perm -o+w 2>/dev/null
```

Breakdown:

|Part|Meaning|
|---|---|
|`find /`|Search entire filesystem|
|`-path /proc -prune`|Skip `/proc`|
|`-o`|OR|
|`-type d`|Only directories|
|`-perm -o+w`|World writable|
|`2>/dev/null`|Hide errors|

Useful directories:

- `/tmp`
    
- `/var/tmp`
    
- backup directories
    

---

# Writable Files

## Find Writable Files

```bash
find / -path /proc -prune -o -type f -perm -o+w 2>/dev/null
```

Look for:

- writable scripts
    
- cron files
    
- config files
    

Potential escalation:

- Inject commands into root scripts.

# Disk Enumeration

## List Disks & Partitions


Example:

```text

├─sda1   8:1    0   29G  0 part /
```

Purpose:

- Find extra drives
    
- Discover hidden partitions
    
- Backup disks

# Capabilities Enumeration

## Find Linux Capabilities

```bash
getcap -r / 2>/dev/null
```

Capabilities can allow:

- reading files
    
- binding ports
    
- privilege escalation
    

Example:

```text
/usr/bin/python3 = cap_setuid+ep
```

Potential root shell:

```python
import os
os.setuid(0)
os.system("/bin/bash")
```
