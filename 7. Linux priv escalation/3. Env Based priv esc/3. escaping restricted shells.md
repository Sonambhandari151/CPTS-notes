# Escaping Restricted Shells - Notes

---

# Restricted Shell

A restricted shell limits what commands/users can do.

Used to:

- prevent dangerous commands
    
- restrict directory access
    
- limit environment modification
    
- control user actions
    

Common in:

- enterprise systems
    
- shared servers
    
- kiosk systems
    
- limited user accounts
    

---

# Types of Restricted Shells

|Shell|Description|
|---|---|
|`rbash`|Restricted Bourne shell|
|`rksh`|Restricted Korn shell|
|`rzsh`|Restricted Z shell|

---

# RBASH

## Full Form

Restricted Bourne Again Shell

## Restrictions

- cannot use `cd`
    
- cannot modify `PATH`
    
- cannot run commands with `/`
    
- limited command execution
    

---

# RKSH

## Full Form

Restricted Korn Shell

## Restrictions

- limited command execution
    
- cannot modify shell environment
    
- cannot create/modify shell functions
    

---

# RZSH

## Full Form

Restricted Z Shell

## Restrictions

- limited aliases
    
- limited scripting
    
- restricted environment modification
    

---

# Restricted Shell Escape Techniques

---

# 1. Command Injection

## Idea

Inject extra commands into allowed commands.

---

## Example

Allowed command:

```bash
ls -l
```

Injected command:

```bash
ls -l `pwd`
```

---

## What happens

Backticks execute:

```bash
pwd
```

Suppose output is:

```bash
/home/user
```

Final command becomes:

```bash
ls -l /home/user
```

---

# Important Point

Even if `pwd` is restricted directly,  
it executes inside command substitution.

---

# 2. Command Substitution

## Idea

Execute commands inside:

```bash
` `
```

or

```bash
$()
```

---

## Example

```bash
echo $(whoami)
```

Runs:

```bash
whoami
```

then prints result.

---

# 3. Command Chaining

## Idea

Run multiple commands together.

---

## Common Operators

|Operator|Meaning|
|---|---|
|`;`|run next command always|
|`&&`|run if previous succeeds|
|`\|`|pipe output|

---

## Example

```bash
ls ; id
```

or

```bash
ls && whoami
```

---

# Goal

Execute unrestricted command after allowed command.

---

# 4. Environment Variable Abuse

## Idea

Modify environment variables like:

```bash
PATH
```

to execute malicious commands.

---

## Example

```bash
PATH=.:$PATH
export PATH
```

Adds current directory to PATH.

---

## Malicious Example

Create fake `ls`:

```bash
echo 'id' > ls
chmod +x ls
```

Now typing:

```bash
ls
```

executes local malicious script.

---

# 5. Shell Functions

## Idea

Create functions that execute commands.

---

## Example

```bash
function sys() { /bin/sh; }
```

Run:

```bash
sys
```

May spawn unrestricted shell.
