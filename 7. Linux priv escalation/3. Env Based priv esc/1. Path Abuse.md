# PATH Abuse — Short Notes

## What is PATH?

`PATH` is an environment variable containing directories where Linux searches for executables.

Check PATH:

```bash
echo $PATH
or 
env | grep PATH
```

Example:

```bash
/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin
```

---

# How Commands Work

When you type:

```bash
ls
```

Linux searches directories in PATH order:

1. `/usr/local/sbin`
    
2. `/usr/local/bin`
    
3. `/usr/sbin`
    
4. `/usr/bin`
    
5. `/sbin`
    
6. `/bin`
    

Finds first matching executable and runs it.

---

# PATH Abuse Idea

If attacker can:

- write into PATH directory
    
- modify PATH variable
    

they can replace legitimate commands with malicious ones.

---

# Add Current Directory to PATH

```bash
PATH=.:${PATH}
export PATH
```

Now `.` (current directory) is searched first.

---

# Verify

```bash
echo $PATH
```

Output:

```bash
.:/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin
```

---

# Malicious Binary Example

Create fake `ls`:

```bash
touch ls
echo 'echo "PATH ABUSE!!"' > ls
chmod +x ls
```

Run:

```bash
ls
```

Output:

```bash
PATH ABUSE!!
```

Instead of real `/bin/ls`.
