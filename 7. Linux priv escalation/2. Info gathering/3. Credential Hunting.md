# Credential Hunting Cheat Sheet

|Command|Purpose|
|---|---|
|`grep 'DB_USER\|DB_PASSWORD' wp-config.php`|Extract WordPress database credentials|
|`find / ! -path "*/proc/*" -iname "*config*" -type f 2>/dev/null`|Find configuration files across system|
|`ls ~/.ssh`|List SSH keys and SSH-related files|

---

# 1. Extracting Credentials from WordPress

## Command

```bash
grep 'DB_USER\|DB_PASSWORD' wp-config.php
```

## Use

Searches inside `wp-config.php` for:

- database username
    
- database password
    

---

## Breakdown

|Part|Meaning|
|---|---|
|`grep`|Search text inside file|
|`'DB_USER\|DB_PASSWORD'`|Search for either `DB_USER` OR `DB_PASSWORD`|
|`\|`|OR operator in grep|
|`wp-config.php`|WordPress configuration file|

---

## Example Output

```bash
define( 'DB_USER', 'wordpressuser' );
define( 'DB_PASSWORD', 'WPadmin123!' );
```

---

## Important Notes

### `wp-config.php`

Main WordPress configuration file.

Usually contains:

- DB username
    
- DB password
    
- database host
    
- salts/keys
    

---


# 2. Searching for Configuration Files

## Command

```bash
find / ! -path "*/proc/*" -iname "*config*" -type f 2>/dev/null
```

---

## Use

Search the entire system for files containing:

- `config`
    


Very useful for credential hunting.

---

## Breakdown

|Part|Meaning|
|---|---|
|`find /`|Search entire filesystem|
|`! -path "*/proc/*"`|Exclude `/proc`|
|`-iname "*config*"`|Match files containing `config`|
|`-type f`|Only files|
|`2>/dev/null`|Hide permission errors|

---

### Why `/proc` excluded?

`/proc` is virtual kernel filesystem:

- not real files
    
- noisy output
    
- process-generated data
    

---

## Common Valuable Config Files

|File|Possible Data|
|---|---|
|`wp-config.php`|WordPress DB creds|
|`.env`|API keys/secrets|
|`config.php`|App credentials|
|`settings.py`|Django secrets|
|`database.yml`|Rails DB creds|
|`sshd_config`|SSH settings|

# 3. SSH Key Enumeration

## Command

```bash
ls ~/.ssh
```

---

## Use

Lists SSH-related files for current user.

---

## Example Output

```bash
id_rsa  id_rsa.pub  known_hosts
```

---

# SSH File Explanation

|File|Meaning|
|---|---|
|`id_rsa`|Private SSH key|
|`id_rsa.pub`|Public SSH key|
|`known_hosts`|Previously connected hosts|

---

# Important Notes

## `id_rsa`

Private key used for authentication.

If readable:

```bash
cat ~/.ssh/id_rsa
```

Can possibly SSH as that user:

```bash
ssh -i id_rsa user@target
```

---

## `known_hosts`

Contains fingerprints of previously connected systems.

Useful for:

- lateral movement
    
- discovering internal systems
    
- pivoting
    

---

# Common Credential Hunting Locations

|Directory|Why Important|
|---|---|
|`/var/www/`|Web app configs|
|`/var/mail/`|Emails/passwords|
|`/home/*/.ssh/`|SSH keys|
|`/opt/`|Custom apps/scripts|
|`/backup/`|Old backups|
|`/etc/`|Service configs|
|`/tmp/`|Temporary scripts/files|

---

# Common Useful Searches

## Find passwords

```bash
grep -Ri "password" /var/www 2>/dev/null
```

---

## Find usernames

```bash
grep -Ri "user" /var/www 2>/dev/null
```

---

## Find secrets

```bash
grep -Ri "secret" / 2>/dev/null
```

---

## Find SSH keys

```bash
find / -name "id_rsa" 2>/dev/null
```
