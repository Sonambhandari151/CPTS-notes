

---

## 1. Goal of Enumeration

```text
Identify OS, kernel, users, groups, services, network, and sensitive files
→ Used for privilege escalation & lateral movement
```

---

## 2. Quick Initial Checks (Situational Awareness)

```bash
whoami          # current user
id              # user + groups
hostname        # system identity
ifconfig / ip a # network interfaces
sudo -l         # sudo privileges
```

### Important Point

- `sudo -l` can directly lead to root access if misconfigured
    

---

## 3. System Information

### OS Version

```bash
cat /etc/os-release
```

**Purpose:**

- Detect distro (Ubuntu, CentOS, Debian, etc.)
    
- Check for known exploits
    

---

### Kernel Version

```bash
uname -a
# OR
cat /proc/version
```

**Purpose:**

- Identify kernel exploits
    
- Check vulnerability exposure
    

---

## 4. Environment Variables

### PATH (command execution search order)

```bash
echo $PATH
```

**Use:**

- Misconfigured PATH → privilege escalation risk
    

---

### All environment variables

```bash
env
```

**Look for:**

- passwords
    
- API keys
    
- sensitive configs
    

---

## 5. Hardware / System Details

```bash
lscpu   # CPU info
```

**Use:**

- System architecture (x86_64, ARM)
    
- VM detection (VMware, etc.)
    

---

## 6. Login Shells Available

```bash
cat /etc/shells
```

**Why important:**

- Check available shells (bash, sh, dash, tmux, screen)
    
- Outdated shells → exploit possibility (e.g., Shellshock)
    

---

## 7. Security Mechanisms (Check existence)

Look for:

- AppArmor
    
- SELinux
    
- iptables / ufw
    
- Fail2ban
    
- Snort
    

**Note:**

```text
Often not fully readable without root
```

---

## 8. Disk & File Systems

### Block devices

```bash
lsblk
```

### Mounted file systems

```bash
df -h
```

### fstab (auto mounts)

```bash
cat /etc/fstab
```

**Use cases:**

- Find mounted disks with secrets
    
- Identify unmounted drives
    
- Access backup storage
    

---

## 9. Network Awareness

### Routing table

```bash
route
# OR
netstat -rn
```

### ARP table

```bash
arp -a
```

### DNS config

```bash
cat /etc/resolv.conf
```

**Purpose:**

- Identify internal networks
    
- Discover other hosts
    
- Domain environment hints
    

---

## 10. User Enumeration

### All system users

```bash
cat /etc/passwd
```

**Format:**

```text
username:x:UID:GID:info:home:shell
```

---

### Only users with login shells

```bash
grep "sh$" /etc/passwd
```

**Meaning:**

- Shows real users (not system service accounts)
    

---

### Get usernames only

```bash
cut -f1 -d: /etc/passwd
```

---

## 11. Password Hash Types (for cracking)

```text
$1$   → MD5 (salted)
$5$   → SHA-256
$6$   → SHA-512
$2a$  → BCrypt
$7$   → Scrypt
argon2 → Argon2
```

---

## 12. Group Enumeration

### All groups

```bash
cat /etc/group
```

---

### Check specific group members

```bash
getent group sudo
```

---

### Important groups to check

- sudo → privilege escalation
    
- adm → log access
    
- docker / lxd → container breakout risk
    

---

## 13. Home Directory Recon

```bash
ls /home
```

**Check inside each user:**

- `.bash_history`
    
- `.ssh/` (keys)
    
- config files
    
- scripts
    

---

## 14. Hidden Files & Directories

### Hidden files

```bash
find / -type f -name ".*" -exec ls -l {} \; 2>/dev/null
```

### Hidden directories

```bash
find / -type d -name ".*" -ls 2>/dev/null
```

**Important files found:**

- `.bash_history`
    
- `.ssh/id_rsa`
    
- `.config`
    
- `.bashrc`
    

---

## 15. Temporary Storage Locations

### Check temp directories

```bash
ls -l /tmp /var/tmp /dev/shm
```

---

### Behavior difference

```text
/tmp:
- deleted on reboot
- auto-clean ~10 days

/var/tmp:
- survives reboot
- kept ~30 days

/dev/shm:
- RAM-based storage (very fast, volatile)
```

---

## 16. Mounted vs Unmounted Storage

### Mounted FS

```bash
df -h
```

### Unmounted FS

```bash
cat /etc/fstab | grep -v "#"
```

**Risk:**

- Hidden partitions
    
- Backup drives
    
- Sensitive data storage
    

---

## 17. Key Attack Opportunities 

```text
1. sudo misconfig → root access
2. kernel version exploit
3. writable PATH abuse
4. .ssh private keys
5. .bash_history secrets
6. mounted backup drives
7. services running as root
8. reused passwords across users
```
