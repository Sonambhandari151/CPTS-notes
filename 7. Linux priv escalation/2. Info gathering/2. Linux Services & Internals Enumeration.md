# Linux Services & Internals Enumeration — Cheat Sheet

|Command|Use|
|---|---|
|`ip a`|Show network interfaces and IP addresses|
|`cat /etc/hosts`|View local hostname mappings|
|`lastlog`|Show last login details of users|
|`w`|Show logged-in users and activity|
|`history`|Show command history|
|`find / -type f \( -name *_hist -o -name *_history \) -exec ls -l {} \; 2>/dev/null`|Find history files|
|`ls -la /etc/cron.daily/`|List cron jobs|
|`find /proc -name cmdline -exec cat {} \; 2>/dev/null \| tr " " "\n"`|Enumerate running process command lines|
|`apt list --installed \| tr "/" " " \| cut -d" " -f1,3 \| sed 's/[0-9]://g' \| tee -a installed_pkgs.list`|List installed packages and save output|
|`sudo -V`|Show sudo version|
|`ls -l /bin /usr/bin/ /usr/sbin/`|Enumerate binaries|
|`for i in $(curl -s https://gtfobins.org/api.json \| jq -r '.executables \| keys[]'); do if grep -q "$i" installed_pkgs.list; then echo "Check for GTFO: $i";fi; done`|Check installed GTFOBins binaries|
|`strace ping -c1 10.129.112.20`|Trace system calls of ping|
|`find / -type f \( -name *.conf -o -name *.config \) -exec ls -l {} \; 2>/dev/null`|Find configuration files|
|`find / -type f -name "*.sh" 2>/dev/null \| grep -v "src\|snap\|share"`|Find shell scripts|
|`ps aux \| grep root`|Show root-owned running processes|

# 1. Network Interfaces

## Command

```bash
ip a
```

## Purpose

Shows:

- IP address
    
- Network interfaces
    
- Internal networks
    
- VPN/tunnel interfaces
    
- Additional NICs for pivoting
    

## Important Findings

- Multiple interfaces may allow pivoting.
    
- Internal IP ranges help identify subnet structure.
    
- IPv6 may bypass filtering/firewalls.
    

Example:

```bash
inet 10.129.203.168/16
```

# 2. Hosts File

## Command

```bash
cat /etc/hosts
```

## Purpose

Shows local hostname mappings.

## Important Findings

Can reveal:

- Internal servers
    
- Domain names
    
- AD naming conventions
    
- Hidden environments
    

Example:

```bash
127.0.1.1 nixlpe02
```

# 5. Command History

## Command

```bash
history
```

## Purpose

Displays previously executed commands.

## Important Findings

Can reveal:

- Passwords
    
- SSH connections
    
- Backup scripts
    
- Internal systems
    
- Credentials
    

Example:

```bash
ssh ec2-user@dmz02.inlanefreight.local
```

# 6. Finding History Files

## Command

```bash
find / -type f \( -name *_hist -o -name *_history \) -exec ls -l {} \; 2>/dev/null
```

## Purpose

Finds shell/application history files.

## Important Findings

May expose:

- User actions
    
- Tokens
    
- Credentials
    
- Script activity
    

---

# 7. Cron Jobs

## Command

```bash
ls -la /etc/cron.daily/
```

## Purpose

Lists scheduled daily cron jobs.

## Important Findings

Cron jobs often run as root.

Look for:

- Writable scripts
    
- Weak permissions
    
- Relative paths
    
- Custom scripts
    

These may lead to privilege escalation.

---

# 8. `/proc` Enumeration

## Command

```bash
find /proc -name cmdline -exec cat {} \; 2>/dev/null | tr " " "\n"
```

## Purpose

Reads command-line arguments of running processes.

## Important Findings

Can reveal:

- Credentials
    
- SSH sessions
    
- Tokens
    
- Running scripts
    
- Internal connections
    

Example:

```bash
ssh-agent
sshd:
htb-student
```

---

# 9. Installed Packages

## Command

```bash
apt list --installed | tr "/" " " | cut -d" " -f1,3 | sed 's/[0-9]://g' | tee -a installed_pkgs.list
```

## Purpose

Lists installed packages and versions.

## Important Findings

Useful for finding:

- Vulnerable software
    
- Old package versions
    
- Useful tools
    

Interesting tools:

- python
    
- perl
    
- gcc
    
- nc
    
- docker
    
- lxd

- Privilege escalation bugs
    
- Authentication bypass vulnerabilities
    

Example:

# 11. Binary Enumeration

## Command

```bash
ls -l /bin /usr/bin/ /usr/sbin/
```

## Purpose

Enumerates installed binaries.

## Important Findings

Look for:

- GTFOBins binaries
    
- Rare admin tools
    
- SUID-capable programs
    

Common dangerous binaries:

- bash
    
- awk
    
- cp
    
- curl
    
- tar
    
- find
    
- vim
    

---

# 12. GTFOBins Enumeration

## Command

```bash
for i in $(curl -s https://gtfobins.org/api.json | jq -r '.executables | keys[]'); do if grep -q "$i" installed_pkgs.list; then echo "Check for GTFO: $i";fi; done
```

## Purpose

Checks installed binaries against GTFOBins database.

## Important Findings

Can identify binaries usable for:

- Sudo abuse
    
- SUID abuse
    
- Shell escape
    
- File read/write
    
- Privilege escalation
    

Example:

```bash
Check GTFO for: bash
Check GTFO for: awk
Check GTFO for: curl
```

---

# 13. `strace`

## Command

```bash
strace ping -c1 10.129.112.20
```

## Purpose

Traces system calls made by a program.

## Important Findings

Useful for:

- Reverse engineering
    
- Watching file access
    
- Monitoring network communication
    
- Identifying loaded libraries
    

Important syscalls:

- `execve` → execute program
    
- `openat` → open file
    
- `socket` → create socket
    
- `connect` → connect remotely
    
- `sendto` → send packets
    
- `recvmsg` → receive packets

# 14. Configuration Files

## Command

```bash
find / -type f \( -name *.conf -o -name *.config \) -exec ls -l {} \; 2>/dev/null
```

## Purpose

Finds configuration files.

## Important Findings

May contain:

- Credentials
    
- API keys
    
- Database passwords
    
- Internal paths
    
- Tokens
    

High-value configs:

- Apache
    
- MySQL
    
- Redis
    
- SSH
    
- Docker
    

---

# 15. Script Enumeration

## Command

```bash
find / -type f -name "*.sh" 2>/dev/null | grep -v "src\|snap\|share"
```

## Purpose

Finds shell scripts.

## Important Findings

Scripts may contain:

- Hardcoded passwords
    
- Weak permissions
    
- Root commands
    
- Backup routines
    

Example:

```bash
/home/htb-student/automation.sh
```

---

# 16. Running Root Processes

## Command

```bash
ps aux | grep root
```

## Purpose

Shows processes running as root.

## Important Findings

Look for:

- Custom scripts
    
- Python processes
    
- Cron jobs
    
- Misconfigured services
    

Interesting examples:

```bash
/usr/bin/python3
/usr/sbin/cron
/usr/lib/snapd/snapd
```

Custom root-owned processes are strong privilege escalation targets.
