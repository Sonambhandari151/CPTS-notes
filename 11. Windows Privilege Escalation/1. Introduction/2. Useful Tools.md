# Useful Tools

## Tool Reference Table

| Tool                                                                                                     | Description                                                                                                                                                                                                                                                                                       |
| -------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Seatbelt](https://github.com/GhostPack/Seatbelt)                                                        | C# project for a wide variety of local privilege escalation checks                                                                                                                                                                                                                                |
| [winPEAS](https://github.com/carlospolop/privilege-escalation-awesome-scripts-suite/tree/master/winPEAS) | Searches for possible privesc paths on Windows hosts. All checks explained [here](https://book.hacktricks.wiki/en/windows-hardening/checklist-windows-privilege-escalation.html)                                                                                                                  |
| [PowerUp](https://raw.githubusercontent.com/PowerShellMafia/PowerSploit/master/Privesc/PowerUp.ps1)      | PowerShell script finding common misconfiguration-based privesc vectors; can also exploit some found issues                                                                                                                                                                                       |
| [SharpUp](https://github.com/GhostPack/SharpUp)                                                          | C# version of PowerUp                                                                                                                                                                                                                                                                             |
| [JAWS](https://github.com/411Hall/JAWS)                                                                  | PowerShell privesc enumeration script written for PowerShell 2.0                                                                                                                                                                                                                                  |
| [SessionGopher](https://github.com/Arvanaghi/SessionGopher)                                              | Finds/decrypts saved remote-access session info — PuTTY, WinSCP, SuperPuTTY, FileZilla, RDP                                                                                                                                                                                                       |
| [Watson](https://github.com/rasta-mouse/Watson)                                                          | .NET tool enumerating missing KBs and suggesting matching privesc exploits                                                                                                                                                                                                                        |
| [LaZagne](https://github.com/AlessandroZ/LaZagne)                                                        | Retrieves stored passwords from browsers, chat tools, databases, Git, email, memory dumps, PHP, sysadmin tools, wireless configs, internal Windows password storage, and more                                                                                                                     |
| [Windows Exploit Suggester - Next Generation (WES-NG)](https://github.com/bitsadmin/wesng)               | Based on `systeminfo` output — lists OS vulnerabilities and matching exploits. Supports every OS from Windows XP through Windows 10 (and Server counterparts)                                                                                                                                     |
| [Sysinternals Suite](https://docs.microsoft.com/en-us/sysinternals/downloads/sysinternals-suite)         | Includes [AccessChk](https://docs.microsoft.com/en-us/sysinternals/downloads/accesschk), [PipeList](https://docs.microsoft.com/en-us/sysinternals/downloads/pipelist), [PsService](https://docs.microsoft.com/en-us/sysinternals/downloads/psservice) — used throughout this module's enumeration |

> [!tip] Precompiled binaries
> Precompiled **Seatbelt**/**SharpUp**: [Ghostpack-CompiledBinaries](https://github.com/r3motecontrol/Ghostpack-CompiledBinaries). Standalone **LaZagne** binaries: [releases page](https://github.com/AlessandroZ/LaZagne/releases/).
>
> **Best practice: always compile tools from source when using them in a client environment.**

> [!tip] Where to upload tools
> If limited writable directories are available, `C:\Windows\Temp` is usually a safe bet — the `BUILTIN\Users` group has write access there by default.
