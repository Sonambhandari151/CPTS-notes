# Legacy Operating Systems

> [!info] Context
> While this module primarily focuses on modern operating systems (Windows 10 / Windows Server 2016), certain issues (vulnerable software, misconfigurations, careless users, etc.) cannot be solved merely by upgrading to the latest Windows versions. Specific security improvements made over the years no longer affect modern, supported Windows versions. During assessments, legacy operating systems will be encountered — especially against large organizations such as universities, hospitals/medical organizations, insurance companies, utilities, and state/local government.

## End of Life Systems (EOL)

> [!info] What EOL means
> Microsoft eventually stops offering ongoing support for a given OS version — meaning it stops releasing security updates. Systems first enter an "extended support" period before being classified end-of-life. Microsoft can continue producing security updates for large organizations through custom long-term support contracts.

## Impact

| Issue | Description |
|---|---|
| Lack of support from software companies | Certain applications (web browsers, other essential apps) may cease working once a Windows version is unsupported. |
| Hardware issues | Newer hardware components will likely stop working on legacy systems. |
| Security flaws | The big one — with notable exceptions like CVE-2020-1350 (SIGRed) or EternalBlue (CVE-2017-0144), easily exploitable and "wormable" flaws affecting thousands of systems worldwide (including critical infrastructure such as hospitals). Microsoft no longer releases security updates for EOL systems, leaving them open to unpatched RCE and privesc flaws until upgraded or retired. |

> [!warning] Real-world constraint
> Organizations may find it difficult or impossible to upgrade/retire an EOL system due to cost and personnel constraints — the system may run mission-critical software no longer supported by the original vendor. Common in medical settings and local government, where the vendor for a critical application has gone out of business or stopped support, leaving the org stuck on Windows XP or even Server 2000/2003. If discovered during an assessment, discuss with the client to understand the business reasons and suggest mitigations such as strict network segmentation to isolate the systems until they can be properly addressed.

> [!info] Field experience
> Server 2000/XP boxes vulnerable to MS08-067 are rare today but do still exist. Server 2003 and 2008 hosts are more common. These systems are often vulnerable to one or more RCE or local privesc vectors, making them a great foothold into an environment. Always check with the client before attacking legacy hosts to ensure they aren't fragile hosts running mission-critical applications that could suffer a massive outage.
