
# **Pivoting, Tunneling, and Port Forwarding – Notes**

---

## **1. Introduction**

- In red teaming / pentesting:
    
    - We may have:
        
        - credentials
            
        - SSH keys
            
        - hashes
            
        - access tokens
            
- But:
    

```text
Target systems may NOT be directly reachable
```

---

## **2. Pivoting**

- Definition:
    

```text
Using a compromised host to access other networks
```

- Purpose:
    
    - Reach **previously unreachable network segments**
        
    - Bypass network segmentation
        
- When possible:
    
    - Host has:
        
        - multiple network adapters (dual-homed)
            

---

## **3. Names for Pivot Host**

- Pivot Host
    
- Proxy
    
- Foothold
    
- Beach Head System
    
- Jump Host
    

---

## **4. Key Idea of Pivoting**

```text
Move deeper into the network through another compromised host
```

---

## **5. Tunneling**

- Definition:
    

```text
Encapsulating traffic inside another protocol
```

- Purpose:
    
    - Hide real traffic
        
    - Avoid detection
        
- Example:
    
    - HTTP / HTTPS
        
    - SSH
        
    - VPN
        

---

## **6. Tunneling Analogy**

```text
Hide a key inside a toy → looks normal outside
```

---

## **7. Lateral Movement**

- Definition:
    

```text
Move between systems inside same network
```

- Purpose:
    
    - Expand access
        
    - Gain more privileges
        

---

## **8. Example of Lateral Movement**

- Compromise one machine
    
- Use same credentials on other machines
    
- Access more hosts
    

---

## **9. Pivoting Example**

- Network is segmented
    
- Find host connected to:
    
    - both networks
        
- Use it to access isolated network
    

---

## **10. Tunneling Example**

- Hide C2 traffic inside:
    
    - HTTP GET/POST requests
        
- Looks like normal web traffic
