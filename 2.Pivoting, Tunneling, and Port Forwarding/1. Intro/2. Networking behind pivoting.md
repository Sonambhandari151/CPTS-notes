

### IP Addressing & NICs

- Every device on a network must have an **IP address** to communicate.
    
- IP addresses are assigned in two ways:
    
    - **Dynamic (DHCP server)** → automatically assigned
        
    - **Static** → manually configured (common for servers, routers, printers, switches, etc.)
        
- IP addresses are assigned to a **Network Interface Controller (NIC)** (also called Network Interface Card / Network Adapter).
    
- A computer can have **multiple NICs**, so it can have **multiple IP addresses**.
    
- Each NIC allows communication on a different network.
    

### Checking NICs

- Linux/macOS: `ifconfig`
    
- Windows: `ipconfig`
    

### Types of Interfaces (Linux example)

- **eth0 / eth1**
    
    - Physical or virtual Ethernet interfaces
        
- **lo**
    
    - Loopback interface (127.0.0.1 → local system only)
        
- **tun0**
    
    - VPN tunnel interface (used in HTB / remote labs)
        

### IP Address Types

- **Public IP**
    
    - Routable over the internet
        
    - Assigned to internet-facing interfaces
        
- **Private IP**
    
    - Used inside local networks (LAN)
        
    - Not directly accessible from the internet
        
- **Loopback IP**
    
    - 127.0.0.1 → internal system communication
        
- **VPN/Tunnel IP**
    
    - Used for secure connection to remote networks (e.g., HTB labs)
        

### NAT (Network Address Translation)

- Converts private IPs into public IPs for internet communication
    
- Required for internet access from private networks

## Routing

### Routing Concept

- Routing decides where network packets are sent.
    
- Every system has a **routing table**.
    

### Routing Table Usage

- Command:
    
    - Linux: `netstat -r` or `ip route`
        
- Routing table contains:
    
    - Destination network
        
    - Gateway
        
    - Interface (NIC used)
        

### Key Terms

- **Gateway / Default Gateway**
    
    - Router used to send traffic outside local network
        
- **Default Route**
    
    - Used when no specific route matches destination
        
- **Iface**
    
    - NIC used to forward traffic
        

### Packet Flow

- System checks routing table → decides:
    
    - If destination is local → send directly
        
    - If remote → send via gateway
        

### Important Idea for Pivoting

- Compromised host routing table helps identify:
    
    - Which networks are reachable
        
    - Possible pivot paths

## Protocols, Services & Ports

### Protocols

- Rules for network communication (e.g., HTTP, TCP, FTP)
    

### Ports

- Logical identifiers for services (software-based, not physical)
    
- Example:
    
    - HTTP → port 80
        
- One IP can have many open ports → many services
    

### Connections

- Client uses:
    
    - Destination port (service)
        
    - Source port (temporary, random)
        

### Security Insight

- Some ports must remain open (e.g., 80 for web traffic)
    
- Attackers often use allowed ports to gain access or pivot

## Pivoting Insight (Important Concept)

- Pivoting depends on:
    
    - NICs and their IPs
        
    - Routing table visibility
        
    - Accessible networks from compromised host
        
- More NICs = more network reach = more pivot opportunities
