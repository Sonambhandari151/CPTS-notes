## 🔹 What happens internally

sshuttle:

- Connects via SSH
    
- Runs Python server on Ubuntu
    
- Adds iptables rules on YOUR machine
    

👉 Effect:

```text
Traffic to 172.16.5.x → auto routed via Ubuntu
```

# 🔹 Behind the scenes (INTERVIEW LEVEL)

sshuttle does:

```bash
iptables -t nat -A OUTPUT -d 172.16.5.0/23 → redirect
```

Then:

```text
Redirect → SSH tunnel → Ubuntu → internal network
```
