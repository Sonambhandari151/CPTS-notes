
 Use Windows machine to create a **SOCKS tunnel via SSH using Plink**, then send RDP traffic through it.

---

# 🧠 WHAT EACH THING DOES

### 🔹 1. `plink.exe`

- Windows version of SSH
    
- Used to create:
    

```text
SOCKS proxy (like ssh -D)
```

---

### 🔹 2. SOCKS Proxy (port 9050)

- Entry point for your traffic
    
- Anything sent here → goes through Ubuntu → internal network
    

---

### 🔹 3. Proxifier

- Forces Windows apps (like RDP) to use SOCKS proxy
    
- Without it, Windows apps won’t use proxy automatically
    

---

### 🔹 4. mstsc.exe

- RDP client
    
- Used to connect to Windows target
    

---

## 🟢 STEP 1 — Start Plink (create tunnel)

```bash
plink -ssh -D 9050 ubuntu@10.129.15.50
```

👉 What happens:

```text
Your Windows → SSH → Ubuntu
```

AND

```text
Local SOCKS proxy starts at 127.0.0.1:9050
```

---

## 🟢 STEP 2 — Configure Proxifier

Set:

```text
Proxy: 127.0.0.1
Port: 9050
Type: SOCKS
```

👉 Now:

```text
All apps → forced through SOCKS tunnel
```

---

## 🟢 STEP 3 — Start RDP (mstsc)

```text
mstsc.exe → connect to 172.16.5.19
```

---

### 🔥 What ACTUALLY happens

Even though you type:

```text
172.16.5.19
```

Real flow is:

```text
mstsc → Proxifier → 127.0.0.1:9050
        ↓
      Plink (SSH)
        ↓
      Ubuntu
        ↓
      Windows target (172.16.5.19)
```

---



```text
Windows (you)
   ↓
Plink (SSH tunnel)
   ↓
Ubuntu (pivot)
   ↓
Internal Windows (RDP)
```
